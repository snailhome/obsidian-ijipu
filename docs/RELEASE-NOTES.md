# 爱记谱 iJipu 0.34.0

> **本版主题：把"三处预览"的工具条与编辑行为统一到底，并让 ` ```jps ` 代码块也拥有完整的源码编辑体验。**
> 0.33.x → **0.34.0**（MINOR：新增"代码块内 iJipu 着色 / 错误提示 / 逐行自动格式化"这一组能力，
> 以及三处工具条与编辑入口的统一下沉；**既有谱面与 `.jps` 语法零改动**）。

## ` ```jps ` 代码块：与手机端 `.jps` 源码编辑**同一套**三项能力（本版核心）

用户原话：「jps 代码块应同时应用**自动格式化、脚本颜色高亮和错误提示**功能，与手机版 jps 文件的源码编辑模式一致」。

- **脚本着色**：围栏内的正文按引擎 `tokenizeJpsLine` 分词上色（与应用、与手机端 `.jps` 源码**同一份规则、
  同一套配色**）——不再借用 Markdown 的代码块高亮；
- **错误提示**：只解析**围栏内的正文**（不含围栏行），行号**偏移回文档行号** ⇒
  行级淡红/淡橙底 + 错误块红/橙单线外框 + 鼠标悬停显示「message + 正确写法」；
- **逐行自动格式化**：光标离开**块内正文行**时按引擎 `formatLine` 规范化该行（与应用的逐行格式化同一份实现）；
- **只在围栏内生效**：笔记里其它 markdown 文本与其它语言的代码块**完全不受影响**；
  且自动格式化**只认已闭合的围栏块** —— 用户忘写收尾围栏时，绝不悄悄改写其正文（数据安全优先）。
- 口径细节：```` ``` ```` 与 `~~~` 都支持、长度 ≥3、info 串允许 `jps` 后带别的词；
  **未闭合**的围栏按 CommonMark 延伸到文末（这样刚敲下 ` ```jps ` 就有着色与提示，而不是"什么都没发生"）。

## 三处预览（`.jps` 文件 / `![[x.jps]]` 嵌入 / ` ```jps ` 代码块）的工具条统一

- **按钮统一为：试听、排版、设置、视图、编辑**（「编辑」固定在**最右**，用**带笔图标**）；
- **「编辑」的行为分派**：**PC** ⇒ 用嵌入版 iJipu 打开编辑；**手机** ⇒ 用 Obsidian 编辑器打开源码（源码模式）；
  **代码块** ⇒ 切换该代码块的源码（桌面与手机端都有 —— 手机端此前**没有**编辑入口）；
- **点左侧文件列表的 `.jps` 一律先显示谱面预览**（PC 与手机一致；原来桌面端会直接塞进嵌入版）；
- **块右上角那枚 `</>` 取消**（图标指示不明、只在桌面端、且与工具条重复）；
- **点击预览区显/隐工具条**（各端各模式）：点一下出现、再点一下收起；
  · 触摸交互下**禁用"悬停自动收起"**（触摸会合成鼠标事件，否则会"刚显示就隐藏"）；
  · 交互式元素（工具条自身、谱面内链接）不参与切换；
  · 另附一条**诊断**（设置 → 说明：「点击预览区显/隐工具条」）—— 记下平台与命中的元素，便于定位。

## 代码块工具条的位置

- 由"贴块外侧"改为**块内预留一条空带**（容器 `padding-top` + 工具条锚容器顶边）：
  既不压谱面墨迹、也不会与**相邻代码块**的工具条互相压住；
- 位置**纯由 CSS 决定、与阅读/编辑模式无关** ⇒ 两种模式**必然一致**
  （原来由"命中测试"判定落位，两种模式结论不同 ⇒ 位置不一致）。

## 其他修复

- **手机端排版虚线拖不动**：虚线拖拽原来只挂 `mousedown`（触摸不产生 `mousemove`）⇒ 改用 **Pointer Events**
  （鼠标/触摸/触控笔通吃），并加 `touch-action: none`（否则浏览器把手势当滚动、直接掐断），
  触摸端再给一条外扩 12px 的**透明命中带**（手指不如鼠标精准）；
- **关闭排版虚线后墨迹四周空白偶发不消除**：裁剪的"补量"条件太窄（只补"完全没量到"，
  而"量到的盒几乎等于整页"也可能是**量得太早**）⇒ 两种情形都补量一次，并把重试阶梯从 3 档加长到 5 档（最远 3s）；
- **点「编辑」打不开嵌入版**（`Failed to fetch dynamically imported module: node:http`）：
  `node:http`/`node:crypto` 必须**静态导入** —— 插件产物是 CJS，静态导入编译成 `require("node:http")`（渲染进程可用），
  而动态 `import('node:http')` 会被当成浏览器模块请求、必然失败。手机端安全性由**调用侧**保证
  （`./embed/server` 只在桌面端被动态 import）；
- **嵌入版打开失败不再留空白**：页签给出**具体原因 + 「重试」按钮**，失败原因并记入
  「设置 → iJipu → 说明 → 嵌入版本地服务（诊断信息）」；失败后可重试（不再留下一个永远失败的 promise）；
- **嵌入版开关关闭时不再打开"死页签"**：点「编辑」改为**退回源码编辑**并提示开关位置；
  音色库入口则直接送到设置「说明」页（那里有音色库入口）；
- 设置页与 README 的文案**与行为对齐**（不再写"点 `.jps` 就用完整编辑器打开"）。

## 引擎同步

- 本版**未改引擎**：`vendor/engine` 与应用引擎仍**逐文件哈希一致**（有闸门）；
- 嵌入版仍为 **v0.51.2**（`adj733` 闸门断言嵌入版版本 == 应用 `APP_VERSION`）。

> **跟随版 + 插件自身更新**（MINOR）：① **同步引擎** `0.40.1 → 0.41.0`（调号 `1 = D`/♯/♭ 同口径、
> 动态谱相机/时间轴/跳跳球的纯函数、音色库与 GM/民族乐器若干）；② **内嵌应用** `0.70.1 → 0.71.0`
> （音色库体系、动态谱视频、卡片模板、官网音色库页）；③ 插件自身 **`adj1009`** 两笔：

## 引擎 0.40.1 → 0.41.0

- **调号显示同口径**：`keySignatureOf` 统一描述头预览与动态谱片头的调号解析，
  `1 = D` / `1 = ♯C` / `1 = ♭E` 的角标与字母顺序一致（`adj1068`）。
- **动态谱纯函数**：时间轴拍段、流式视图/出帧、相机推近与跟拍、跳跳球逐拍落点；
  桌面端出片使用，插件预览不启用（`adj1028`–`adj1078`）。
- **音色库**：SF2 头解析、库注册表 v2、按库收藏、GM 128 名称、民族乐器拟声、音色表缺省不再静默回退
  （`adj1009`–`adj1028`）。
- **渲染/排版**：小节序号与歌词的垂直顺序、调号角标、动态谱描述头相关修正。

## 内嵌应用 0.70.1 → 0.71.0

- **音色库体系**：首次为空、发现/导入、桌面 curl 下载、资源安装包目录
  `%LOCALAPPDATA%\iJipu\soundfonts`、官网 `/soundfonts/` 推荐页。
- **动态谱视频（桌面端专属）**：相机位 + 9:16/1:1/16:9 + 3 分钟/整首/标记段 + 片头片尾卡片 +
  卡片模板/自定义/zip + MP4。**插件内与网站一致，不显示入口与相机位**。
- **卡片风格**：深空蓝 / 纸面 / 水墨 / 极简；自定义（颜色/字体/水印/背景图）保存在本机 L1。
- **用户手册**：新增音色库、动态谱视频、卡片模板与 zip 迁移章节。

## 插件自身（`adj1009`）

- **`7a715be` 预览跟随嵌入版主题**：Obsidian 的自动/浅色/深色会传给嵌入版 iJipu，
  预览不再与应用自身主题打架。
- **`fcecc56` 打印/导出 PDF 强制浅色**：Obsidian 深色主题下不会把谱面导出成深底。

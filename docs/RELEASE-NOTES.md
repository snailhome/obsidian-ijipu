# 爱记谱 iJipu 0.45.0

> **跟随版（引擎同步 + 嵌入版同步）**（MINOR）：引擎 `0.44.0 → 0.45.0`（新增间奏标记
> `{jz N}`、`playback/sync` 对拍数学、`playhead` 间奏块）；内嵌应用 `0.74.2 → 0.75.0`
> （外部伴奏 / 对拍台 / 前奏等待 / 混音 / 侧车 sidecar / 桌面原生文件操作）。
> 插件自身**无代码改动**，只同步 `vendor/engine` 与内嵌应用。

## 内嵌应用 0.74.2 → 0.75.0

- **外部伴奏 + 对拍台**：`.jps.sync.json` 侧车、波形/时间标尺/音符格子、0/1/2+ 锚点、
  保留段、混音三档与两条音量、前奏等待；`.jps` 旁边有伴奏时自动读。
- **间奏标记 `{jz N}`**：`0{jz 16}` 按 16 拍播放、排版按谱面时值；间奏块中性灰；
  片头卡速度写「实际（原谱 X）」。
- **桌面端文件操作统一原生**（桌面壳专属）：打开 / 另存为 / 选伴奏都拿真实路径；
  sidecar 与伴奏按真实路径读写；网页/插件仍按各自平台能力降级。
- **练习段/音量跟着 sidecar 走**：练习段列表、当前选中段、相机导出段与音量自动保存，
  刷新后恢复；试听里增删练习段立即写盘。
- **出片/相机位**：前奏等待、保留段、相机「输出声音」、播放中改音量即时生效。

## 引擎 0.44.0 → 0.45.0

- 新增 `engine/interlude.ts`（`{jz N}` 解析/格式化/注记等价）与 `engine/playback/sync.ts`
  （锚点拟合、单锚点偏移、拍 ↔ 音频毫秒）；
- `dynamic/timeline` / `types` / `playhead` / `sequence` 增加间奏块与同步相关字段；
- 以上均为向后兼容新增，不改既有谱面语法。

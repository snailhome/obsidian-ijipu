# 爱记谱 iJipu 0.44.1

> **跟随版（引擎同步）**（PATCH）：① **同步引擎** `0.41.0 → 0.42.0`（相机「左右露白 ≤10%」夹紧修正、
> 曲行纵向归组 `rowSpansOfPage`、成片流式视图按曲行取景）；② **内嵌应用** `0.72.0 → 0.73.0`
> （平移方式、试听纵向滚动、成片曲行取景）；③ 品牌图标同步为应用 `adj1061` 的新版；插件自身**无代码改动**。

## 引擎 0.41.0 → 0.42.0

- **相机露白夹紧修正**（`E-2026-512`）：`[x0 − halfW + m, x1 + halfW − m]` 把符号写反了，
  实际只约束"露白 ≤90%"、且"整行放得下 ⇒ 居中"分支永不命中；改为 `clampRowCenter` 的
  `[x0 + halfW − m, x1 − halfW + m]`，阈值 `CAMERA_WHITE_MARGIN = 0.1` 单列（出片与试听共用）。
- **新增 `rowSpansOfPage`**：按**曲行**归组（`page.voiceBlocks` 认多声部块、`{bz}`/`{dsb}`/`{tp}` 段层
  并入所属曲行、行底取到最后一行歌词）——试听纵向滚动与成片取景共用；**不再按"行间空隙"合并**
  （多声部行距含歌词区，实测会把同组两声部拆成两行，`E-2026-513`）。
- **流式视图按曲行取景**：`buildFlowView` 的行改用 `rowSpansOfPage`，删掉 `ROW_MERGE_RATIO`。

## 内嵌应用 0.72.0 → 0.73.0

- **平移方式**（`adj1089`）：设置 → 本机 新增「跟随（4/5→1/5）/ 按拍 / 按小节」；出片与试听同一份偏好，
  切下拉会重建相机会话。
- **试听纵向滚动**（`adj1090`）：首次播放 / 换行时把「曲部 + 词部」整行滚进视界
  （多声部同组；多行歌词都算；行比视口高时先保曲部；每个曲行只触发一次）。
- **成片相机按曲行取景**（`adj1091`）：同组多声部 + 段层 + 歌词一起框住，相机纵向中心 = 曲行中心。

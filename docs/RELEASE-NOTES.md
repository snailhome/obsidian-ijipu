# 爱记谱 iJipu 0.36.0

> **本版是功能版**（MINOR）：谱面工具条定稿为 **5 位**、新增「**⋯ 更多**」菜单（含**复制为图片**与**导出范围**）、
> 新增代码块**块级缩放 `z`**；并把**内嵌的 iJipu 应用**更新到 **v0.53.0**（含「范围」盒通道）。
> 0.35.2 → **0.36.0**。**既有谱面与 `.jps` 语法零改动**。

## 工具条：固定 5 位，低频入口进「⋯ 更多」

`▶ 试听` ｜ `☰ 排版` ｜ `谱面·页面` ｜ `✎ 编辑` ｜ `⋯ 更多`

- **「设置」「格式化」「在应用中打开」「打开谱面文件」移入菜单**（工具条只留高频操作）；
  菜单项触发的仍是原来那批按钮 —— 处理器一行没改，行为与之前完全一致。
- **桌面在预览区右键** = 打开**同一份菜单**；**手机**点「⋯ 更多」是**底部弹出的大行高面板**
  （Obsidian 在手机上本来就把它渲染成底部面板）⇒ 三处**共用同一份菜单数据**，不会各写一份再漂。
- **手机端**：按钮 **≥44px**（此前 24–30px，手指偏小）、工具条**常驻不自动收起**、
  不依赖悬停、不依赖右键；「在应用中打开」在手机上**不出现**（嵌入版视图只在桌面注册）。

## 新增：「复制」组

`⋯ 更多 → 复制`：

- **复制为图片**（**2× 默认** / 1× / 4×）：渲染在**嵌入版应用**里做（与 GUI 导出**同一套**），
  插件再给 PNG 写上**物理密度（pHYs）**后放进剪贴板 ⇒ 2× = **144 DPI**、4× = **288 DPI**，
  粘进 Word / 微信 / 飞书**就是合适大小**（没有这一项时它们会按 96 DPI 兜底，把一张 2× 的 A4 谱
  插成 **12 英寸的巨图**）。
  多页谱**只复制第 1 页**并如实说明；当前环境不支持写入剪贴板图片时**明确报错**，并指向「导出 PNG」命令。
- **复制 SVG 文本**（矢量，含「导出范围」裁剪）、**复制谱面源码**（`.jps` 原文）。

## 新增：「导出范围」

`⋯ 更多 → 导出范围`（与「设置 → 说明 → 导出范围」是**同一个值**）：

| 选项 | 画布口径 |
|---|---|
| **页面**（默认） | 整页（A4 等）+ 四周留白 —— 与改动前一致 |
| **谱面** | **墨迹包围盒 + 每边 2px**（不保留页宽） |
| **跟随视图** | 谱面模式 ⇒ 按「谱面」；整页 / 满宽 ⇒ 按「页面」 |

- 「导出 SVG / PNG」与「复制 SVG 文本」都按它裁；「导出谱面」与**谱面视图**用的是**同一份几何**
  （所以"预览看到的就是导出的"）。
- 选「谱面」需要先在预览里显示过这份谱（面板会实测墨迹盒）；**量不到墨迹**、
  或**预览与嵌入版的页面尺寸不一致**（例如两边纸张设置不同）时**明确报错** ——
  不会悄悄给你一张整页图、也不会裁出一张错位的图。
- 默认仍是「页面」：面板初始显示模式就是「谱面」，若默认跟随视图，升级后**导出尺寸会静默变化**。

## 新增：代码块块级缩放 `z`

写在代码块的**语言名后面**：

    ```jps z=150
    D: C
    P: 4/4
    Q: 1 2 3 4 |
    ```

- **缺省 / `z=100`** ⇒ **100%（自然尺寸）**：1 个 viewBox 单位 = 1 CSS px ⇒
  笔记里只有一两行曲部时**不再被拉伸放大**（这是本功能的由来）；
- `z=<数字>`（1–1000）⇒ 百分比；**`z=*`** ⇒ **自适应笔记栏宽**（= 本功能上线前的行为）；
- **只对笔记里的代码块生效**（`.jps` 文件视图与 `![[x.jps]]` 嵌入保持原样）；
- **只影响屏幕显示**：导出/复制仍按「导出范围」的口径，与 `z` 无关。

## 内嵌应用更新到 v0.53.0

内嵌的 iJipu 应用更新到 **v0.53.0**（含「范围」盒通道与 PNG 物理密度工具）。
不更新的话，选「导出谱面」时**应用不认范围盒**、会给你一张整页图 —— 本版已按项目的
「**先定稿应用版本 → 再重生成嵌入产物 → 再发插件**」顺序重生成；插件冒烟 `adj733`
会核对"内嵌版本号 == 应用版本号"。

## 既有功能与数据

`.jps` 语法、谱面排版几何、设置项含义**均无破坏性改动**；`.jps` 文件、笔记里的代码块、
试听、排版辅助虚线、页面设置等照旧可用。

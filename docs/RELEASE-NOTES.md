# 爱记谱 iJipu 0.44.2

> **跟随版（引擎同步）**（PATCH）：① **同步引擎** `0.42.0 → 0.43.0`（相机 `rowLeadMs` 行末提前换行、
> 色块调色键改「声部+音色」、新增 `primaryVoiceOf`）；② **内嵌应用** `0.73.0 → 0.74.0`
> （行末提前平移量、按小节 4/5 安全推、多声部分色、片尾版式与背景图）；插件自身**无代码改动**。

## 引擎 0.42.0 → 0.43.0

- **相机行末提前**（`adj1094`）：`buildCameraTrack` 新增 `rowLeadMs`——换行的横向 pan 与纵向 `cy`
  都提前这么多毫秒**完成**（行判定也提前 `rowLeadMs + lineMs`）；`0` = 行首那一下瞬间归位（旧行为）。
- **按拍/按小节的行首关键帧**（`E-2026-514`，`adj1092`）：每个曲行无条件补一条行首关键帧
  （时刻取该行第一块自己的 `t0`），网格比色块早几毫秒时也不丢；**按小节的行内 4/5 安全推**
  （`E-2026-515`，`adj1093`：除本行最后一个小节外，色块越过画面 4/5 就推）。
- **多声部色块分色**（`E-2026-516`，`adj1095`）：`instrumentColorMap` / `playheadBaseOf` 的调色键
  改为 **`声部|音色`** ⇒ 同一音色在不同声部也分色；`instrumentColorMap` 的参数收窄成最小形状
  （视频的 `TimedRect` 可直接传入）。
- **跳跳球只落第一声部**：新增 `primaryVoiceOf()`（只认主声部角色，有 voice 1 就只用 voice 1，
  没有才退到最小声部号）。

## 内嵌应用 0.73.0 → 0.74.0

- 设置 → 本机 新增「**行末提前**」：`0 / 0.5（默认）/ 1 / 1.5 / 2 拍`；三种平移模式都按它提前换行
  （横向 + 纵向）；**平移方式默认改为「按拍」**。
- 试听：按拍/按小节每行都移（行末→行首不再掉帧）；按小节行内 4/5 安全推（最后一个小节除外）。
- 多声部：色块按「声部 + 音色」分色（视频也逐块取色，不再一律红）；跳跳球落第一声部。
- 片尾卡：纵向间距按字号比例排（标题↔标语墨迹空白 1.1×标题字号）、强调线居中；
  导出视频的片头/片尾卡恢复**自定义背景图**（`E-2026-517`）。

## 插件自身

- 无代码改动；仅随引擎 / 嵌入版同步。
- 插件冒烟里 `adj452` 的旧口径断言（"同一音色恒定同色"）按新键同步为
  「同声部同音色恒定同色 + 不同声部同音色必须分色」（`adj1095` 的口径变更）。

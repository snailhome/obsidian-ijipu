# 爱记谱 iJipu 0.29.0

> **嵌入版：在 Obsidian 里直接用完整的 iJipu 编辑 `.jps`**（不必再装外部桌面端）。
> 0.28.3 → **0.29.0**（MINOR：新增"嵌入版"能力）。

## 一、嵌 入 版（本次重点）

- **左侧栏出现「爱记谱」图标**（设置里可关）：点开是一个**完整的 iJipu**
  —— 编辑、排版、试听、导出都在，和网页版 / 桌面版是同一个应用。
- **以当前 Obsidian 文库为工作区**：不需要选文件夹、不需要文件系统授权，文件树就是你的文库。
- **打开库里的 `.jps` 就是完整编辑器**（不再只是"轻量预览 + 源码框"）。
  笔记里 **`![[xx.jps]]` 仍是原来的轻量预览**（笔记里塞一个完整编辑器既难看也没必要），
  它的工具栏按钮由「应用打开」改为「**编辑**」，点它用嵌入版打开这份谱。
- **打开方式可选**（设置 → iJipu → 嵌入版 → 「打开 .jps 的方式」）：
  | 选项 | 行为 |
  |---|---|
  | **右侧栏**（默认） | 在右侧边栏打开，不抢主编辑区 |
  | 新的页签 | 在主编辑区新开一个页签 |
  | 当前页签 | 就地替换当前页签 |
  | 默认应用 | 交给系统里关联 `.jps` 的程序（仅桌面端） |
- **即时保存**：在嵌入版里编辑即写回那份 `.jps`（写入后回读校验，失败会明说）；
  **撤销 / 重做历史照常**（不采用"只存缓存"的方式）。
- **检测外部修改**：若该 `.jps` 在 Obsidian 那边被改动，会提示「**重新载入 / 保留我的修改**」。
- **深浅色跟随**：你的深浅设置会被**记住**；选「跟随系统」时自动跟随 Obsidian 的主题切换。
- **设置只有一处**：「设置 → iJipu」只保留「嵌入版」与「说明」两页 ——
  排版（页面/字体/行距/渲染）与音色，统一在**嵌入版 iJipu** 里改，避免两处设置互相打架。
- **工作区不打扰**：嵌入版里不再出现「工作区」页签与菜单项（文件操作交给 Obsidian）。
- 关掉「使用嵌入版 iJipu」开关即完全回到原来的轻量渲染（**可回退**）。

## 二、本次修掉的问题（全部来自真机实测）

| 现象 | 原因 | 处理 |
|---|---|---|
| 点库里的 `.jps` 打开的是"未命名"，并提示"还没有设工作区…" | 工作区记录归一化时把**没有句柄/路径**的记录当损坏记录丢掉了 | 放行"宿主桥"记录（文库工作区） |
| 点「新工作区」报 `SecurityError: … Cross origin sub frames aren't allowed to show a file picker` | 浏览器**禁止跨源子框架**弹文件选择器 | 嵌入版里不再出现"选文件夹/切换工作区"入口；「打开/另存为」改走工作区 |
| 嵌入版**图标全都不显示** | 资产里有中文文件名，浏览器把 URL **百分号编码**，而服务用原始串查表 ⇒ 永远查不到 | 服务侧 `decodeURIComponent` 后再查表 |
| 点 `.jps` **只展开了右栏，应用里没打开那份谱** | 靠 `ViewState` 令牌让视图自己去取"要打开的文件"，而复用页签时 Obsidian **不重建视图** | 改为**直接驱动视图实例**（并等 iframe 就绪） |
| 「新的页签 / 当前页签」都开成了右侧栏 | 一条"已有嵌入页签就复用"的规则**压过了模式选择** | 去掉该规则：**模式有最终决定权** |
| 点 `.jps` 留下一个"已在爱记谱中打开…"的中间页签 | `.jps` 绑定文件视图，Obsidian 必然创建它 | 打开完成后**自动关掉**该中间页签 |
| 页签名显示「爱记谱」而不是文件名 | 页签名来自 `getDisplayText()` | 打开谱时显示**文件名**，未打开时显示「爱记谱」 |
| **点 A 显示 B**（打开的不是点的那份） | 应用启动时的"恢复上次绑定"与宿主推来的文件**并发**，而它用的是**函数开头的陈旧快照**判断 ⇒ 恢复后完成、把刚打开的那份覆盖 | 认领绑定提前到第一个 `await` 之前；并在**落笔前重读实时状态**，已有更新绑定即放弃恢复 |
| 深浅主题"没记住" | 应用启动时**无条件**用宿主主题覆盖了用户的 `themeMode`（还把它写进了存储） | 不再覆盖用户的显式选择；"跟随"改为走应用自己的 `auto` 语义 |
| 嵌入版设置重启后回到默认 | `localStorage` 按 **origin** 隔离，而服务端口每轮随机 ⇒ 每轮都是"新站点" | ① 服务优先**固定端口**；② 设置改走**宿主存储**（落在插件 `data.json`） |

## 三、体积与隐私

- 嵌入版网页（含 37 个图标与全部前端资源）**内联进 `main.js`**：发布物**仍是三个文件**
  （`main.js` / `manifest.json` / `styles.css`，`main.js` 约 2.8 MB）。
- 未使用的资源（PWA 图标 `Jianpu.ico`/`pwa-*.png`、8 个遗留 SVG 等）**不打包**。
- 嵌入版页面由一个**仅本机**的本地服务承载（`127.0.0.1` + 一次性令牌）：**不联网、不对外**。
  文件读写全部经 Obsidian 的文库接口完成。

## 四、升级方式

插件市场更新即可。首次点开「爱记谱」图标会启动上述本地服务承载该页面。

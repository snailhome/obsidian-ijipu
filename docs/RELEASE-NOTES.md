# 爱记谱 iJipu 0.36.2

> **本版是参数改名版**（PATCH）：代码块的视图参数由 `m=` 改名为 **`v=`**
> （`v=p` 整页 / `v=w` 满宽 / `v=s` 谱面），与应用、网页文档页口径统一；
> 同时把**内嵌的 iJipu 应用**从 0.53.1 更新到 **0.55.1**。0.36.1 → **0.36.2**。
> **既有谱面与 `.jps` 语法零改动** —— 只有"代码块参数"这一处写法变了，见下。

## 改：代码块视图参数 `m=` → `v=`（`adj887`）

在笔记里写 `` ```jps m=p `` 的那套参数，**键名改成 `v=`**：

| 旧 | 新 | 含义 |
|---|---|---|
| `m=p` | **`v=p`** | 整页（含页边距） |
| `m=w` | **`v=w`** | 满宽（只按宽度铺满） |
| `m=s` | **`v=s`** | 谱面（裁到墨迹，**默认**） |

- **为什么改**：这三档本质是**视图**，插件内部的类型本来就叫 `ViewMode`；`m`（mode）语义偏抽象。
  应用与网页文档页**同一次改完**，两端不会再各写各的。
- ⚠ **`m=` 不再被识别**：用户口径是"这个参数才设置的，可以直接改，减少代码臃肿" ⇒
  **直接替换、不保留旧名兼容**。若你的笔记里写过 `m=…`，改成 `v=…` 即可。
  写错的值（如 `v=x`）照旧**有明确提示**、不会静默退化成默认视图。
- **`z=`（缩放）不变**：语义清晰，不动。

## 更新：内嵌的 iJipu 应用 0.53.1 → **0.55.1**

插件里那个"嵌入版 iJipu"（桌面端点左侧栏图标打开的完整编辑器）随之更新，跨了三个应用版本：

- **0.54.0**：命令行独立成 `@ijipu/cli` 包 + 应用侧「能力宿主」命名管道；
- **0.55.0**：**官网分层**（介绍首页 + `/app/` + `/manual/` + `/syntax/`）、
  `` ```jps `` 代码块变成可交互示例、深浅主题、Obsidian 插件专区；
- **0.55.1**：修桌面版「点官网首页没反应」（Tauri opener 权限缺 URL scope）、
  内置音源与许可同目录、播放跟随滚动改「安全区」（提前量 + 顺滑）。

> 嵌入版产物按项目的**顺序铁律**生成：先在应用仓库定稿版本号，再 `build:embed` + `embed-emit`。
> 跨仓闸门 `adj733`（嵌入版产物版本 == 应用 `APP_VERSION`）因此**由红转绿**。

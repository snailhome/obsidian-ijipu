## 一、试听色块右界：按"墨迹"夹紧，不再压到下一个音符（引擎 adj732）

用户口径（应用与插件都适用）：

> 色块右界**不超小节线左界，不超下一音符（包括倚音）、滑音等属于下个音符的元素
> 和 `&zkh`/`&ykh`/`&hx` 等独立修饰符**。

**根因**：色块右界把**步进右端**（`x + width`，本音到下一个音的推进量）当成了墨迹右端 ——
等距音符时它恰好等于下一个音的 `x`（看着"还挺准"），一旦下一个音排得更近就压过去。
截图那句实测：第 2 音 `x=133.2 w=58.2 ⇒ 右缘 191.4`，而附点音 `x=177.2` ⇒ **压过 14.2px**。

**现在**：右界 = `min(本音墨迹右缘, 下一个元素的最左墨迹, 小节线左界, 独立修饰符左界)`。
其中"下一个"按**时间**判定（和弦音同拍、x 只差零点几像素，不算"下一个"），
"最左墨迹"含**倚音组 `[5/]`、变音角标、滑音记号**（它们画在数字左侧）。
段层（`{bz}`/`{dsb}`）同一原则：有下一个段内音符时取它的左缘。

## 二、音源（音色库）改到**插件目录**，随文库一起走（adj729）

- 落点：`<配置目录>/plugins/ijipu/soundfonts/<库 id>.sf2`（走 `vault.adapter`，因为 `.obsidian/` 是配置目录）。
- 取用顺序：**插件目录文件 → IndexedDB → 内置 → 联网下载**；**下载成功后写回插件目录**；
  老的 IndexedDB 缓存在首次读到时会**自动补写**成文件（无感迁移）。
- 嵌入版应用**不再自己下 32 MB、也不再各存一份**：宿主把这份文件的 URL 交给它（`welcome.bankUrls`）。
- 嵌入版里点「导入音色文件」改由**插件**导入：插件在 Obsidian 窗口里弹一次文件选择器、
  直接把字节写进插件目录（32 MB 走 `postMessage` 传要 base64 ≈43 MB，慢且吃内存，这样搬都不用搬）。
- ⚠ 想让它"随文库走"，同步工具需要包含 `.obsidian`（Obsidian Sync 需打开「已安装的社区插件」）。

## 三、修掉三个"只有插件才会遇到"的问题

**① 嵌入版试听/导出**无声** —— 本地服务没提供 SpessaSynth worklet（adj727b）**

应用按 `./spessasynth/spessasynth_processor.min.js` 取 worklet，而它**不在**嵌入版资产白名单里
⇒ 插件的本地服务对未知路径回 **204** ⇒ `audioWorklet.addModule` 拿到空模块必然失败。
现在服务用**插件已内联在 main.js 里的那份 worklet**顶上（不额外增体积）；没传时**响亮地 500**，
而不是又静默 204。

**② 试听失败提示太短、也没有入口（adj728）**

- 两处音源失败提示（打开试听面板时的后台预取 / 点播放时加载失败）都带上「**打开音色库**」按钮
  → 直接打开嵌入版 iJipu 的「设置 → 音色库」；**带按钮的提示不自动消失**。
- ` ```jps ` 预览里试听失败的提示同样改成**常驻 + 按钮**（旧的是 6 秒消失、没有任何入口）。
- 「设置 → 音色库」面板新增「**打开下载页**」按钮与三步引导（下载 → 导入 → 即可试听）——
  该直链在部分网络不可达（jsDelivr 又因单文件 20 MB 上限 403），自动下载**必然失败**，
  手动导入是唯一可行路子。

**③ 嵌入版「支持作者」赞赏码破图（adj731）+ 入口恢复（adj730）**

- 入口：上次"设置整并"时把设置页的「支持作者 ❤」一起删掉了，本轮补回，
  并**把赞赏码直接显示出来**（与应用同一张图，构建期内联，不联网；白底以便扫码）。
- 破图：`DonateDialog` 用的是根绝对路径 `/icons/good.png`，嵌入版跑在
  `http://127.0.0.1:<port>/<token>/` 下 ⇒ 少了 `<token>` 段 ⇒ 本地服务一律 404。已改走 `BASE_URL` 口径。

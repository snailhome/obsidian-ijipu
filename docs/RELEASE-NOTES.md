# 爱记谱 iJipu 0.28.3

> 随 `@ijipu/engine` **0.31.0** 同步：**跳房子（volta）反复/跳跃规则重写**——
> 注释编号即遍次、计数在进入下一遍时减 1、`]`/`]/` 的封闭与未封闭、`&ds` 需 `&hs`、
> `&fine` 需大反复已生效。
> 0.28.2 → **0.28.3**（PATCH：仅随引擎修复演奏口径，插件自身代码与设置不变）。

**一、跳房子（volta）的演奏口径按用户定案重写**

用户用一个整天、十几轮对话把口径逐条定死，四条合起来才完整：

1. **注释里 `.` 分隔出的编号 = 该房子所属的遍次**——`["1."` ⇒ 第 1 遍；
   `["2.3."` ⇒ **第 2、3 两遍**（计数 2，两遍各奏一次）；`["4."` ⇒ 第 4 遍；
   无数字注释（`["结束句"`）按出现顺序取一个**还没被占用的遍次**。
   注释**只用于**"判断是否同一个房子"与"得到计数"，执行依据是**计数 + 谱面顺序 + 反复/跳跃**。
2. **同注释 = 同一个房子**：共用一份计数，在它所属那一遍里**走到哪处奏哪处**；
   **不同注释属于不同遍次**。
   例：`Q: 1 1 |["1." 1 2 |]["2." 1 3 |]["1." 1 4 :|] 1 5 ||` ⇒ `11 12 14 · 11 13 15`。
3. **计数在"进入下一遍次"时减 1**（不是走过房子末尾线就减）——不管有没有走完；
   走到房子入口：**还有计数 ⇒ 进入演奏**，**计数为 0 ⇒ 跳过该房子范围、继续往下演奏**。
4. **`]` = 明确封闭**（范围就到这根线）；**`]/` = 线画到此处、末尾延伸到后面的反复/跳跃**
   （首选 `:|`/`:|:`，其次 `&dc`/`&ds`/`&fine`）；**`||`/`||/` 不再是未封闭房子的末尾线**。
   同一根线上 **`]` 写在 `[` 前面**（`|]["2."` = 上个房子结束 + 下个房子开始，**画法不变**）。
   房子**不会嵌套**：分界在小节线上，小节内的音符才是演奏的主体。

**二、配套修正**

- **`&ds`（跳花 S）必须有对应的 `&hs` 才生效**——没有花 S 就不跳，不再退回"跳到曲首"；
- **`&fine` 只在"生效的大反复确实发生过"之后才终止**（第一次经过不停）；
- **转调遇到反复、跳跃不恢复调号**，除非有明确的再转调 `"d:X"` 或恢复调号 `"d:"`；
- 「跳房子跨线延续连音线」的合并随之对齐（起音与房子首音并成一个长音）。

**三、升级方式**

插件市场里更新即可（无需改设置）。引擎同步后**行为变化只在跳房子相关的谱面**上体现；
不含跳房子的谱面演奏结果与 0.28.2 完全一致。

# 爱记谱 iJipu 0.26.0

> 随 `@ijipu/engine` **0.28.0** 同步：**临时多声部（`{dsb}`）全面收官**、
> **歌词注释版式定规**、**修饰符层级栈立规**。
> 0.25.2 → **0.26.0**（MINOR：引擎带来多项用户可感知的排版/演奏变化，插件自身写法与设置不变）。

**一、`{dsb}` 临时多声部：看得见的三处变化**

- **第一声部不再被压扁**（`adj693`）——此前 `{dsb}` 与 `{bz}`/`{tp}` 共用"压到 2/3"的缩放，
  第一声部比下层矮一头；现在它按**正常高度**显示，上下两声部等高。
- **不再自动加一对圆括号**（`adj709`）——`{dsb}` 只画大括号；
  你自己写的 `&zkh`/`&ykh` 仍然照画。
- **大括号两侧留白收窄**（`adj692`~`adj718`）——落点改为**居中于"左邻居 ↔ 段内容"之间**，
  总量经过六轮收敛（`2w → w → 1.5w → 1.4w → 等分并封顶`），不再出现"一侧空一大片"。
  > 你最后要求的「两侧留白合计 15px」**这一版没做到**（实测 25.7px）：
  > 那个区间由**段内容的拍位映射**决定（实测 30.9px），不是留白参数能压的；
  > 要真正做到需要把段内容整体右移，会改变音符位置。**待你确认基准后另行处理。**

**二、`{dsb}` 的演奏：前两拍恢复双声部（`adj710`）**

- **现象**：`{dsb (3// 2// 1//) (1// 1/) 7,/ 1- }` 这类段里，**前两拍听起来不像双声部**。
- **原因**：连音线合并会把"同音高 + 同连线"的后一个音**整个并进前一个音**——
  上层 `(1// 1/)` 同音高被合并、下层 `(6// 6/)` 音高不同没合并，
  于是**上下两层音符数不再一一对应**，全曲 31 个上层音里有 **3 个起奏点被吞掉**。
- **现在**：`{dsb}` 段内**一律不做连音合并**，两层逐音对齐；其它场合的连音合并保持原样。

**三、歌词注释（红字）版式定规（`adj700`~`adj711`）**

五条规则，一次说清：

1. **不占音符位**——只调注释自己的位置，不会把音符或歌词字推开；
2. **不压歌词**，包括歌词字后面的标点（`，。`）；
3. 水平方向**放得下**时，**靠近它后面的那个歌词字**；
4. 放不下时，落在**后面那个字（锚字）的正上 / 正下方**，并**左右居中于该字**
   （此前会飘到**前一个字**的正上方）；
5. 全被占时才退到"以锚字居中"兜底。

**四、其余修复**

- **跳房子线**（`adj696`~`adj699`）：不再穿过段层连音线；第 2、3 间房不再"跳"到上一个曲部
  （同一列 x 在不同曲部完全相同，旧判据分不清）。
- **`{dsb}` 段里 `1-` 的增时线**（`adj694`/`adj703`）：此前段内容宽度算成 0、音符被压成 2px，
  增时线紧贴数字；现在末音块宽 **8.6 → 26.9px**，与主旋律同拍位对齐。
- **`{dsb}` 更密的拍**（`adj702`）：拍宽分配改用**绝对拍位**，与主旋律对齐，不再"一个松一个紧"。
- **独占小节的多拍长音**：色块撑满小节内容右界，末尾不再留双倍空白。

**五、新增「修饰符层级」主规则（`adj714`）**

从音符往上、往下各有固定层级，叠加时**以墨迹不重叠为原则**、层间留 2px：

```
音符往上：① 高八度点 → ② 本音符修饰符（波音/顿音/颤音/注释）
          → ③ 跨音符修饰符（连音线、渐强/渐弱）→ ④ 跨小节/章节修饰符（跳房子、反复）
音符往下：① 减时线 → ② 低八度点 → ③ 其它
```

本版**已把该规则写进项目规范并做成自动断言**；各修饰符的实际落点**未改动**
（现有排列经实测已符合该层级）。

**升级**

- **无需改谱**：不写 `{dsb}`、歌词注释、跳房子的谱面，渲染与演奏结果与之前**逐字一致**。
- 用了 `{dsb}` 的谱面：排版会更紧凑、第一声部变高、多出的圆括号消失——都是本版有意为之。

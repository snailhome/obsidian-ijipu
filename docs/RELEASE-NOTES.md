# 爱记谱 iJipu 0.22.1

> 本轮只改**插件界面**（引擎未变，`vendor/engine` 仍与 `@ijipu/engine` **0.23.0** 逐文件一致）：
> ① 预览工具条上的「未随谱携带 N 项」提示**移进「⚙ 设置」对话框**，紧跟「谱面自带设置 N 项」展示；
> ② 对话框的字段组改成**页签**（页面 / 字体 / 行距 / 渲染 + 说明）；
> ③ 对话框改成**固定大小**，**底部按钮常驻可见**，**页签内容区滚动**。
> 0.22.0 → **0.22.1**（PATCH：纯界面组织方式调整，渲染与试听行为不变）。

**工具条只留按钮，「未随谱携带」挪进设置对话框**

- 预览工具条上那个不可点、只能悬停看明细的黄色徽标**已移除**（工具条现在只剩可点按钮 + 「frontmatter 覆盖 N 项」）。
- 点「⚙ 设置」后，对话框里**紧跟「谱面自带设置 N 项」**多出一块**「未随谱携带 N 项」**（左侧警示色竖条，与绿色的"自带设置"一眼区分），并**逐项列出「标签：值」**（原先只有 tooltip 能看到），块内直接给出去向：「要把这份谱（或只把代码块）复制给别人也显示一致，用下面的『随谱固化（分享用）』」。
- 明细在**点开对话框时现算**（`configCarryover(源码, 生效配置)`），不占工具条位置。

**字段组改成页签**（与「设置 → iJipu」同款）

- 排版对话框现在是 **页面 / 字体 / 行距 / 渲染 / 说明** 五个页签，一屏只看一组、少滚动；复用设置页签的样式与交互。
- **切页签不丢改动**（草稿是对话框级状态），点「恢复默认」重画后也停在同一页。
- 三个保存去向（保存到谱面 / 随谱固化 / 保存为插件默认）的差别收进**「说明」页签**，原先它们挤在对话框顶部。

**对话框固定大小 + 内容滚动 + 按钮常驻**

- 宽高都定死（`min(720px, 94vw)` × `min(82vh, 720px)`）：**切页签不再跳高矮**；高度按视口夹一下，小屏也不会把按钮挤出屏幕。
- 布局是一条定高 flex 列：顶部提示与两块信息卡（信息卡过长时**自己滚**，最多占 32% 高）→ 页签栏 → **字段区（唯一滚动区）** → 底部按钮组（`flex: 0 0 auto`，**永远可见**）。
- 旧的「内容区整体 `max-height: 70vh` + 自己滚」已移除，滚动职责下放给字段区。

**升级**

- 无需任何操作：老笔记的渲染与试听完全不变，只是"设置在哪看、怎么翻"变了。
- 若你在找「未随谱携带 N 项」：它现在在预览工具条的「⚙ 设置」对话框**顶部**（「谱面自带设置 N 项」正下方）。

## 修复：设置页「说明」页签混进了「嵌入版」的内容（`adj922`）

- 用户报「插件的设置页面里说明页签下面赞赏图后面多出了嵌入版页签里的内容」。
- 根因：`src/settings.ts` 的 `paintActive` 里原本是**两句** `if` ——
  `if (说明) renderAbout(panel)` 后面跟 `if (诊断) renderDiagnostics(panel) else renderEmbed(panel)`；
  停在「说明」时第二句的条件不成立 ⇒ 走它**自己的 `else`** ⇒ `renderEmbed` 又把整个「嵌入版」追加到
  **同一个 panel** 上。
- 修法：改成 `if / else if / else` **一条链**（与 `configDialog.ts` 的页签分派同款），
  同时清掉旁边那句「只剩两页」的过时注释（`adj788` 起就是三页）。
- 闸门：`adj922` **10 条**（源码级"必须是一条链"+ 三个页签只往自己的 host 追加；**无头浏览器实测**
  把真的 `src/settings.ts` 打进浏览器包、在仿 Obsidian 夹具里点页签、数每个面板的 item ——
  三页两两不交叉；均带负对照）。

## 修复：`.jps` 的「打开方式」四档行为（`adj923` / `adj926` / `adj931` / `adj934`）

四档逐个修，**改的都是"用哪个 leaf / 什么时候还回去 / 还回去多少"**：

| 档 | 修前 | 修后 |
|---|---|---|
| **当前页签** | 就地替换后还被"还回去"一次 | **就地替换、不再还原**（基准档） |
| **右侧栏** | 每点一次「编辑」**新建一个页签**（右栏越点越多） | **单实例复用**：先 `getLeavesOfType` 找、判 `leaf.getRoot() === workspace.rightSplit`，命中就 `revealLeaf` + 推文件；没有才建 ⇒ **不留多余页签** |
| **默认应用** | 点开**报错** | **不再报错**：改走**宿主 API**（原来 `await import('electron')` 在渲染进程必然失败 —— 原生动态 import 不被 esbuild 转成 `require()`，与 `adj778` 对 `node:http` 记的是同一个坑） |
| **新的页签** | 看着"还是在当前页签里打开"（新 leaf 建了，但把刚建的当前页签 `detach` 掉 ⇒ 页签栏数量与位置都没变） | **真的新开**一个页签，并把来源页签用**宿主自己的历史后退**还原 |

- **"当前页签被刷新"的根因**（在 `obsidian.asar` 1.13.7 里逐句核对，不是猜的）：点文件管理器里的
  `.jps`，宿主走 `getLeaf(false).openFile(file)`，而 `getUnpinnedLeaf()` 里那句
  `if (i && i.canNavigate()) return i` ⇒ **活动 leaf 的视图被就地换掉**（原视图进该 leaf 历史）。
  `setViewState()` 里 `WorkspaceLeaf.open(view)` 的 `old.close()` **第一句**就是
  `containerEl.detach()`、且 `LeafHistory.go(-1)` 在 `this.owner.working` 时**直接中止**（还弹一句
  "页签忙"）⇒ **"一帧都不闪"做不到**（诚实结论）。
- **用户裁定的兜底方案**（`adj934`）：**「右侧栏 / 默认应用」这两档一次还原都不做**，
  就停在该 `.jps` 的**完整预览**上（稳定终态，不再"换掉又翻回来"）。
  代价如实记录：来源页签的导航历史里仍压着那份笔记 ⇒ 用户可按页签栏那枚「←」退回去。
  这一档只在**桌面端 + 嵌入版开着**时才走；手机端 / `![[xx.jps]]` 内嵌本来就停在预览上，一行没动。

## 修复：页签名一律显示 `.jps` 文件名（`adj931`）

- 左边绑文件的 `半山听雨.jps` 之所以对，是因为宿主 `WorkspaceLeaf.updateHeader()` 读
  `view.getDisplayText()`，而 `TextFileView` 基类返回 `this.file.basename`。右边那个是插件的
  **应用级**嵌入版视图（`VIEW_TYPE_IJIPU_APP`，**不绑文件**）：`getDisplayText()` 在**视图创建那一刻**
  就被宿主调用了（那时还没打开文件）⇒ 拿到写死的「爱记谱」；此后改文件名**没有任何东西通知宿主重画页签头**。
- 修法：页签名**一律显示 `.jps` 文件名（含扩展名）**，**含右侧栏那一个实例**；「爱记谱」只在确实没承载
  `.jps` 时出现。同时**打开时不再刷新当前页签**（把"还回去"提前到"选好落点就发出去"之后）。

## 新增：PC 端文件列表里的 `.jps` 直进嵌入版（`adj923` ②）

- 桌面端按设置里的「打开方式」**直接进嵌入版**（右侧栏 / 新页签 / 当前页签 ⇒ 本页签让位、画一句占位后
  路由；默认应用 ⇒ 本页签留预览 + 交给系统默认程序）。
- **手机端 / 笔记里 `![[xx.jps]]` 内嵌仍是轻量预览**；嵌入版起不来 ⇒ **退回轻量预览兜底**
  （换视图前先探 `getEmbedUrl`）；视图里**不塞 iframe**（避免两个地方同时显示同一份谱）。
- 判据抽成**纯函数**（`src/embed/openPlan.ts` 的 `pickRightSidebarLeaf` / `planJpsInitialView`），
  冒烟用假 workspace 真跑并带负对照（连点 3 次「编辑」：新写法右栏 **1** 个页签、旧写法 **3** 个）。

## 引擎同步（应用 0.58.0 的引擎，逐字节同步到 `vendor/engine`）

- **末行自然对齐的基准换成「上一行小节线实位」**（`adj940`）：不再按"上一行小节**内容宽**"对齐，
  而是逐小节反解"要让第 i 根线落在上一行第 i 根线的位置、本小节该占多宽" ⇒ 前 `k−1` 根**精确重合**、
  末根线贴右内容界、逐小节宽 ≥ 上一行对应小节；**删除了旧的「行末 `||` 且 ≤3 小节不参与对齐」豁免**。
- **`align_min_bars` 只对「整份谱的最后一行」生效**（`adj925`/`adj935`）：非末行一律两端对齐撑满；
  「末行」= 整份谱最后一个排版单元的最后一行（"某曲部只有一行"不再算末行）。这个键从此**只管
  "末行撑不撑满"、不管"对齐"** —— 对齐是默认行为、不依赖任何 `# jps-config` 键。
- **连音线弧顶高度改常量 4.5px**（`adj929`）：短弧不再塌、长连音视觉一字不变；渲染 / 布局 / 墨迹盒
  三处取同一个常量。
- **示例谱去掉已不再需要的 `align_min_bars`**（`adj941`）：`public/samples/茉莉花.jps` 只删这一个键、
  其余 17 个键与值逐字保留（那行仍是**非空对象**、**没有**被清空）。
- 插件侧 `vendor/engine` 与本版引擎**逐文件哈希一致**（49 个文件；闸门 `adj770` 绿）。

# 爱记谱 iJipu 0.22.0

> 随 `@ijipu/engine` **0.23.0** 同步：**演奏细节四连**——① 倚音上可以挂**上/下波音**（`2[3/&sby]`）；
> ② **打音 `&da` / 叠音 `&die` 真的会奏出来**（辅助音极短）；③ **上/下滑音**奏成**逐半音的连续滑行**
> （`6&shy` = `5 → 5# → 6`），记号按"滑进本音"的语义画在音的**左侧**（主音符与倚音同侧）；
> ④ **临时段（`{bz}`/`{tp}`/`{dsb}`）里的倚音、装饰、滑音一并奏出**。
> 0.21.0 → **0.22.0**（MINOR：引擎新增语法能力与演奏细节，插件侧解析/排版/渲染/试听随之生效）。

**倚音上可以挂波音了**（引擎 `adj633`）

- 写法：`2[3/&sby]`（单上波音）、`2[3/&xby]`（单下波音）、`2[3/&sby+]` / `2[3/&xby+]`（长上/长下波音）——
  写在倚音括号内、**该倚音数字之后**，记号画在该倚音**正上方**。
- 大小按「波音 : 所属音符」**同一比率**随倚音等比缩小（正好是主音符上的一半大）。
- 倚音括号内可用的 `&` 编码由 5 个扩到 **9 个**（新增 `&sby`/`&xby`/`&sby+`/`&xby+`）；其余编码仍会告警提示。

**打音 / 叠音会奏出来了**（引擎 `adj635`）

- `&die` 叠音 = 上邻音 → 主音（`2 → 1`）；`&da` 打音 = 主音 → 下邻音 → 主音（`1 → 7 → 1`）。
- **辅助音极短**（约为主音符时值的 1/16，夹在 30–70ms），总时值**守恒**、主音至少保留一半；
- 带打音/叠音的音符**不再被同音连音合并**——打音正是用来"把两个相同的音断开"（`(1&da 1)` 两下都听得到）。

**滑音改成"线状"的连续滑行**（引擎 `adj636`）

- `&shy` 上滑音 = 从**下方**的调内二度滑进本音；`&xhy` 下滑音 = 从**上方**滑进本音
  （C 调 `6&shy` = `G4 → G#4 → A4`、`5&xhy` = `A4 → G#4 → G4`）。
- **不改变任何音符的时值**（滑行只占本音符开头，之后按住本音到结束），后续拍位与整曲时长都不动。
- **记号改画在音的左侧**（此前在右侧是错的）：主音符与倚音**同侧**，记号在音的左边才读得通"滑进本音"；
  尺寸与高度不变。紧排的多声部谱面里也不会压到前一个音符（占宽口径同步换边）。

**临时段里的演奏细节补齐**（引擎 `adj637`）

- `{bz}` / `{dsb}` / `{tp}` 段内的**倚音（前/后、长/短）、波音/打音/叠音、滑音**现在都会奏出
  （此前段内只发一个整音事件：记号画了不奏）；时值仍只从本音符里匀，**段内总时长不变**。

**升级**

- 老笔记无需改写法：没写这些记号的谱面，排版与渲染逐像素不变（占宽公式在无记号时与旧版一致）。
- **两点听感/外观变化**请留意：① 写了 `&da`/`&die` 的音符**从此会响**（此前只有记号没有声音）；
  ② 滑音记号的位置（右侧 → 左侧）与奏法（一跳 → 逐半音滑行）都变了。
- 段内倚音/装饰/滑音**从此会发声**；若某段原本靠"不发声"来对齐听感，请听一遍再决定是否保留记号。

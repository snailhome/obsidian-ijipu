## 为什么是 MINOR

插件自身代码零改动，但**内嵌应用带进了一个新能力**（试听「标记段」：段选择、起止标记、循环、
3-2-1 倒数、谱面上的标记线与起止竖头）。对用户来说这是"能做的事变多了"，按 SemVer 走 **MINOR**。

## 引擎：`0.38.6 → 0.39.0`（新增练习段 API）

新增导出（`@ijipu/engine` 与 `vendor/engine` 逐字节一致，闸门 `adj770`）：

- `noteIdStringOf(id)` —— 音符 id 串（`页_声部_组_序号`）；
- `resolvePracticeRange(seq, startId, endId)` —— 把"一对起止"解析成播放区间候选：
  · 端点匹配**三级**：整串精确 → （段层）解码三元组 / （主旋律）组号+序号且**同声部优先** → 就近夹紧；
  · 同一对起止对应多处时给多个候选，并标出 `containsJump`（含跳越）；
- `slicePlaySequenceByRange(seq, i0, i1)` / `slicePlaySequenceByNoteRange(...)` —— 裁段、时间轴从 0 重排，
  并把"起点早于终点音符结束时刻"的事件一并纳入（保证终点音的**附点/增时线**奏完）；
- `extendRangeEndToSlurEnd(seq, i1, slurPairs, result)` —— 按 **token 对象身份**映射把终点延伸到连音线末尾
  （**当前应用界面不再调用**：用户口径是"连音线由用户指定末音，不自动判断"；算法与断言保留备用）。

## 内嵌应用：`0.67.3 → 0.68.0`（试听「标记段」）

- 试听区下方新增**标记段按钮组**：`[▾] 标记段 [段 ▼] [⇤ 起始] [⇥ 停止] [＋ 添加] [－ 删除] [⟲ 循环]`；
  左上角 `▾` 收起整组，收起后**展开按钮挪到歌名前**（不占行）。
- 下拉第一项恒为「无（演奏全曲）」且不可删除；标记按**文档身份**缓存（不写进谱面）。
- 谱面显示**青色细线**（每行一段）+ 起止小竖头；循环开启时两端加 ⟲；**只在试听面板打开时显示**。
- 按段播放；循环时**每遍之间静默 3 秒**；开始与循环重来前在起始竖头左侧显示 **3-2-1 倒数**（白底圆形）。
- 跨 `:|` 回跳的段落：线按**演奏顺序**铺，竖头/倒数落在**实际首末音**上。

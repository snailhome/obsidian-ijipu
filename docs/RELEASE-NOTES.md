# 爱记谱 iJipu 0.48.1

> **补丁版**（PATCH）：修「作者行里有 emoji 时，emoji 图形压到后面的值上」。引擎版本号不变（仍 `0.48.0`），只是 `vendor/engine` 跟到修好的那份代码；内嵌应用不动。

## 修了什么

- 现象：作者两行写作 `苏一 曲` / `蜗牛🐌 制谱` 时，emoji 图形压住「制谱」。
- 原因：作者两端对齐的估宽函数把 emoji 当 **0.55 个字宽**（实际约 1.37），估窄后用 `textLength` 做**负字距**硬压，字形就叠在一起。
- 改法：`layout/authorAlign.ts` 重写估宽 —— emoji 整簇按 **1.5 个字宽**（真机实测 1.37，宁宽勿窄：估大只是标签被拉开，估小才会压字）；ZWJ 组合、肤色修饰、变体选择符都并成一簇只算一个字；汉字/假名/谚文/全角标点算 1 个字宽；ASCII 按字面分档（`M W m w` 一类宽字母 1.0、大写 0.75、小写 0.62、数字 0.6、窄标点 0.35、空格 0.3）。

## 插件自身

- 无功能改动；只是把 `vendor/engine/layout/authorAlign.ts` 同步到含上述修复的版本（`vendor/engine` 其余文件与 0.48.0 一致）。

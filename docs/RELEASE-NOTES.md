# 爱记谱 iJipu 0.7.5

> 本版随 `@ijipu/engine` 同步两项**排版行为**变更（插件侧不需要改代码，只是引擎换新版）：
> ① **短谱不再挤在左边**——一段曲部**只有一行**时（比如只写了一句的谱例），若小节数少于「两端对齐最小小节数」
> （默认 4），整行按该数**预分小节槽**：每小节占一个槽、槽内音符自动摊开，行尾留白；
> 某小节内容实在放不下时，这一小节按自身自然宽度排开、不挤压。
> ② **左右边距默认 40 → 50px**——没在谱面里显式写过边距的笔记，打开后左右留白会比以前宽一些
> （显式写过 `margin_left/margin_right` 的笔记不受影响）。

## 变更：单行曲部按「小节槽」预分占宽（adj421）

- **现象**：只写一到三小节的短谱（插件里常见的"一句谱例"）整行挤在左边一小块里，右边一大片空白；1 小节的 `Q: 1 2 3 4 |` 尤其明显。
- **改法**：**只有一行的曲部**且小节数少于「两端对齐最小小节数」（默认 4）时，整行占宽按该值**预分小节槽**（槽宽 = 行内容宽 ÷ 4）——每小节领一个槽、槽内音符按空间优先摊开；若某小节「本体宽 + 小节线占位」超过槽宽，则该小节保持自然宽（不压缩）。
- **效果**：1 / 2 / 3 小节的单行曲部分别占行宽的 1/4、2/4、3/4，行尾留白；单行 1 小节的每小节几何与「4 小节铺满行」里的一个小节**完全一致**。多行曲部不受影响（末行仍按"对齐前面行"的规则）。

## 变更：左右边距默认 40 → 50px（adj418）

- 没在谱面 `# jps-config` 里写过边距的笔记，渲染时左右留白变宽（每侧多 10px），行内容相应收窄。
- 写过 `margin_left` / `margin_right` 的笔记**不受影响**（显式值优先）。
- 想改回去：在插件设置或谱面设置里把左右边距调回 40 即可（会写进该笔记的 `# jps-config`）。

## 验证

- 引擎 `npm run smoke`：新增 `[106]`「单行曲部小节槽」**两种布局各 8 条**断言（1/2/3 小节的槽位、槽内摊开、本体超槽 → 自然宽、多行曲部不适用），并把受影响的既有几何断言按新规则重算；失败项 17 == 改动前基线。
- 插件侧 `tsc -noEmit -skipLibCheck` 通过；`npm run smoke` **119 项全绿**；`vendor/engine` 与 `ijipu` 引擎**逐文件哈希一致**（本次同步 `types.ts` 与 `layout/index.ts` 两个文件）。
- 应用侧无头 Chrome 实测：1 小节的每小节几何 == 4 小节铺满行的第 1 小节（音符 x 逐一相同）、2 小节的小节间距 = 一槽宽，并截图目视。

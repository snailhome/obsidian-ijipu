# 爱记谱 iJipu 0.16.0

> 本版只做一件事：**同步 `@ijipu/engine`（0.17.0 → 0.18.0）**——带来**倚音时值口径重写**：
> 前倚音改为"占用本音符的时值"（不再借上一个音符），短倚音再加一条
> "本体不足半拍时只取本体一半"的上限。插件自身代码无功能改动。
> 0.15.0 → **0.16.0**（MINOR：聆听倚音与相邻音符的衔接能立刻听出差别）。

## 变更（来自引擎）

- **前倚音改为"占用本音符的时值"**（`adj623`，用户口径）：`1 3[2/] 1` 由「前音 750ms、倚音 750–1000、主音 1000–2000」
  变为「**前音奏满 1000ms**、倚音 1000–1250、主音 1250–2000」；`sequence.ts` 砍掉 adj508 给短前倚音单开的
  "抢在拍点之前 + 借上一个主音符"分支，连带清掉 `prevConsumeMs` 与"回改上一个主音符事件"的 patch。
  **长前倚音与后倚音行为零变化**，仅与短前倚音归于同一口径。
- **短倚音时值补一条上限**（`adj624`，用户口径，`graceGroupBeats` 短倚音分支）：
  `min(主音符因子 × 倚音因子, 本体 ÷ 2)`，"本体"= `tokenDuration({augmentCount:0, dots:0})`
  （**增时线与附点都抹零**）；**前后倚音同一把尺子**。
  短倚音**永远装得进本音符**：`3///[2/]` 由「倚 1/8 = 把整个 1/8 拍音符吃光、主音符 0 拍」
  变为「倚 1/16 + 主 1/16」；`3 -[h2/]` 时值仍按本体 1 拍算 = 1/4 拍、位置在增时线之后。

## 升级

- 听感：`1 3[2/] 1` 这种"前音 + 前倚音 + 后音"组合——前一个音不再被截短，倚音从拍点起奏、主音符顺延。
- `3///[2/]`（1/8 拍短音上的倚音）由"被吃光"变为正常奏出，主音符仍有声。

## 变更说明

- 无破坏性变更：本轮只同步引擎的倚音时值口径；谱面绘制与占位零变化。

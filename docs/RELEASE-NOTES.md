# 爱记谱 iJipu 0.25.0

> 本轮两件事：**新建 `.jps` 的两条入口**（用户要求）+ 随 `@ijipu/engine` **0.25.2** 同步的
> **连音线跨跳房子演奏修复**。
> 0.24.1 → **0.25.0**（MINOR：新增功能）。

**一、文件夹右键 → 「新建 JPS 文件」（用户要求）**

- 文件列表里**右键任意文件夹**，菜单**最上面的「新建」组**里会多一项「**新建 JPS 文件**」
  （排在 Obsidian 自带「新建笔记 / 新建文件夹」之后，与它们同一组）。
- 点它即在**该文件夹**内建一份 `.jps`（**默认模板内容**）并直接打开成谱面视图。
- 重名自动避让：`未命名.jps` → `未命名 1.jps` → `未命名 2.jps`…（与 Obsidian 自带「新建笔记」同款命名，
  取第一个空位；Windows/macOS 上大小写不敏感）。

**二、点击 `[[谱名.jps]]`（文件还不存在）→ 自动创建（用户要求）**

- 以前会建出 **`谱名.jps.md`**：Obsidian 对未解析链接走 `createNewFile(parent, 链接文本)`，
  而 `jps` 扩展名没在它的文件创建器表里注册时**一律回退成 `md`** ⇒ `谱名.jps` + `md`。
- 现在插件把 `jps` **注册进 Obsidian 的创建器表**，于是：
  - 建出来的是**真正的 `谱名.jps`**（不再是 `.jps.md`）；
  - 落在**链接所在笔记的同级目录**下（用户口径）；`[[子/谱.jps]]` 会连子目录一起建，
    `[[/谱库/我的谱.jps]]` 从库根算；`..` 一律拒绝，不往库外写；
  - 内容同样是**默认模板**（Obsidian 那条路径建出来是空文件，插件随后补上模板）。
- 点击链接时走的是插件自己的接管：**先按模板建好再打开**，视图一次就渲染正确。
  别名与子标题（`[[谱名.jps|别名]]`、`[[谱名.jps#第2段]]`）会先剥掉；**不是 `.jps`** 的未解析链接
  （`[[普通笔记]]`、`[[图.png]]`）**不插手**，仍归 Obsidian（照旧建 `.md`）。
- 与 Obsidian 的跟随语义一致：**源码模式**（非实时预览）下要按住 `Ctrl/Cmd` 才跟随链接——
  免得"点一下想放光标，却把文件建出来了"；`Ctrl/Cmd` 点 = 在新页签 / 分屏打开。

**三、随引擎同步：连音线跨跳房子的演奏修复（`@ijipu/engine` 0.25.2）**

- `(5/ |["1." 5/) … :|[+++"2." 5/) … ||/&ds]["结束句" 5/)` 这类"跨房子连音线"，
  房子 2 / 结束句的首音此前被**当成独立半拍**演奏（房子 1 是对的，因为它与起音紧挨着）。
- 现在按普通同音连线口径**并成一个长音**：只起奏一次、时值相加（`5/` + `5/` = 一个 1 拍的 `5`），
  试听色块连续滑过两处。**谱面写法不变**。

**升级**

- **无需改任何谱面**：`.jps` 写法没变。下列情形会按新行为生效（都是本次修正的目标）：
  ① 文件夹右键多出「新建 JPS 文件」；② 点击不存在的 `[[谱名.jps]]` 建出的是 `.jps` 而不是 `.jps.md`；
  ③ 带跨房子延续线的谱子，房子 2 / 结束句首音由"两个半拍"变成"与起音合成一个长音"。

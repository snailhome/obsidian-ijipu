# 爱记谱 iJipu 0.19.1

> 同步 `@ijipu/engine` 0.20.1——两处**默认值/默认位置**按用户口径收口：
> **`S:` 谱尾说明默认靠边距内的右下角**（右缘贴右边距线、末行贴下边距线，改边距整块跟着走），
> **「显示小节计数」默认改为勾选**（没写过该项的笔记现在都显示方框小节序号）。
> 插件自身的设置文档随之更新（README 对照表的默认值必须与引擎一致，由 smoke `[3f]` 守着）。
> 0.19.0 → **0.19.1**（PATCH：只调默认值与默认位置，无新功能）。

**`S:` 谱尾说明的默认位置**（随引擎同步而来，`adj630`/`adj630b`）

- **默认靠"边距内的右下角"**：说明文字整体**右对齐到右边距**——多段 `S:`、以及一段里因超宽
  自动换行的每个子行，右缘都贴同一条线（此前是左对齐、贴左边距）。
- **紧靠下边距线 + 随两条边距线调整**：纵向改为**自下而上**——**末行紧靠下边距线**（字底距线 2px）、
  往上逐行（行距 = 说明字号 × 1.4）。改 `margin_right` / `margin_bottom`，说明整块跟着两条线走。
- **修复**：旧实现"首行在下边距线上方 24px、然后往下逐行排"，**三行以上会越过下边距线跑出页面**；
  现在行数再多也只往上长。
- 用 `⚙ 排版` 拖过说明的笔记仍按你拖到的位置加偏移；「恢复默认」后回到右下角。

**「显示小节计数」默认 = 勾选**（`adj630c`）

- 没写过该项的笔记（含新建）现在都显示方框小节序号：第 4、8、12… 小节各一个（`ijipu_barCountInterval`
  默认仍是 4）。
- 不想要？在 `⚙ 排版` 或设置里取消「显示小节计数」（会写进 `ijipu_showBarCount: false` 或源码 `# jps-config`）。
- 之前显式写过 `true` 的笔记：这一项等于默认值，保存时会顺手去掉（设置行更干净）；写过 `false` 的照旧不显示。

**升级**

- 谱尾说明不用再手动摆位置了；想微调就拖它，或写 `ijipu_metaPos` 自定义。
- 想让某篇笔记不显示小节序号：取消勾选即可（或 frontmatter 写 `ijipu_showBarCount: false`）。

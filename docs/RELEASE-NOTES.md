# 爱记谱 iJipu 0.47.0

> **跟随版（内嵌应用 0.80.0）**（MINOR）：同步引擎 `0.47.0`（连续动态谱 `linear/*` 模块并入 + 隐藏歌词时条带高度修正）；内嵌应用重新生成到 `0.80.0`（右侧栏/浮动栏、告警抽屉、窄栏收尾、乐谱包桌面导出、乐谱库迁出）。插件自身无代码改动。

## 内嵌应用 0.78.0 → 0.80.0

- **右侧操作栏**：除底栏外新增「右侧栏 / 右侧浮动栏」两种壳（两档宽度、页签可放底边或右侧竖排、顶栏常驻开关、设置里选操作方式）；手机只给底栏与浮动栏。
- **告警抽屉**：告警从底栏页签独立成贯穿窗口底部的抽屉（默认收起，`Ctrl+\`` / ESC 开关）；页签组回到 8 个。
- **窄栏与图标**：8 个面板在 320 / 195 档下改成上下排列、不裁内容；顶部、导入、过滤行等按钮改图标；设置标签列 108px，320 档标签全部一行。
- **乐谱包**：桌面端导出后可「打开文件 / 打开文件夹」。
- **乐谱库迁出**：首页与应用示例改读线上数据，旧地址 301 到独立站点。
- 0.79.0（未单独发版）的「视频能力迁到爱出片」也包含在内：应用内不再有动态谱视频/卡片模板/对拍台面。

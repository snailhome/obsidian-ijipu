## 一、默认"无空白"：只显示有墨迹的部分，四周留 2px

- 默认的「谱面」视图本来就裁到**实测内容包围盒**（整页白底、四边距内的空白都不显示）；
  本次把谱面块自身的内边距由 `0.4em`（≈6.4px）收到 **2px** —— 谱面已经贴到墨迹了，
  再套一圈厚边距就是白占地方。
- 「谱面」按钮的悬停说明也写明"四周留 2px"；整页 / 满宽两个视图不受影响。

## 二、进源码 = **切回笔记源码**（不再用插件自己的 textarea）

- 撤掉 0.29.x 里那套"预览块内就地编辑"（插件自己的 textarea + 自动保存 + 移动端键盘适配）：
  它是插件再造的一套编辑器，样式、撤销栈、"打字跳回开头"都要自己兜。
- 改为**把光标送回这篇笔记的这段源码**：阅读视图会先切到**实时预览**（`mode:'source', source:false`），
  光标落到代码块首行、滚进视野、聚焦 —— 之后就是 Obsidian 自带编辑器（原生语法高亮、撤销栈、
  与其它代码块完全一致），**光标移出该块即回到谱面**。
- 定位不到代码块、或这份笔记没有可编辑页签时给出明确提示（不静默）。

## 三、浮动工具条移到**谱面块外侧**左上角

- 工具条（试听 / 排版 / 设置 / 显示模式 / 编辑）改成浮在谱面块**正上方、左缘对齐**（用
  `bottom: calc(100% + 2px)` 贴块顶边）——**不再压住谱面**，于是谱面才能真的只留 2px 留白。
- 显隐口径不变：默认不可见、鼠标移到谱面块上淡入（**导出 PDF / 打印不会带上操作界面**）；
  触屏常显；键盘敲键也能唤醒。
- ⚠ 由此带来一个真实坑：实时预览里 Obsidian 给 widget 容器加了 `overflow: hidden`（悬停时），
  会把浮到块外的工具条**整条裁掉**。插件在挂载时给"承载本面板的那个块"加了一个类来放开裁剪，
  不影响宿主别的块。

## 四、块**右上角**的 `</>`（编辑源码）

- 位置与外观照抄 Obsidian 自己的「编辑此块」：落在块右上角、悬停才显、与工具条同一套显隐。
- 用 `div` + `role="button"`（而不是 `<button>`）：宿主给 `button` 统一套了底色与输入框高度，
  直接沿用会和 Obsidian 那枚长得不一样；键盘 `Enter` / `Space` 同样可触发。
- 实时预览里 Obsidian **自己**也会给代码块挂一枚同样的按钮 —— 插件检测到就撤掉自己那枚
  （不重复挂）；阅读模式下没有宿主那枚，则由插件这枚出场。两条路径**外观一致**。

## 五、修复：三个"只有插件才会遇到"的宿主问题（用户截图逐一复现）

**① 「谱面」视图还留一大片空白（上下都有）—— 挂载瞬间量不到内容盒**

Obsidian 的代码块 / widget 是**先把 DOM 建好、再挂进文档**。插件在挂载那一刻量 `getBBox()`
（元素还没进渲染树）⇒ 一律返回 0 ⇒ 只能退回"按边距裁"（= 整页去掉四边距，上下空白依旧）。
现在：**游离时不量**（省掉一次注定全 0 的测量），并挂两条补量路径 —— `ResizeObserver`
（元素进渲染树时尺寸 0→真实，那一刻补量）与定时重试（下一帧 / +60ms / +300ms）兜底；
补到即写回内容盒并重下一次 viewBox。用户那份谱实测：内容盒 **488×107**（页面 595×842，高度仅 13%）。

**② 小节序号数字偏上、不在方框正中（只有插件偏）—— 宿主 DOMPurify 剥掉了 `dominant-baseline`**

插件的 SVG 原本交给宿主的 `sanitizeHTMLToDom()` 插入，而它底层是 **DOMPurify**，
其 SVG 属性白名单**不含 `dominant-baseline`**（白名单里有 `alignment-baseline`、`baseline-shift`、
`text-anchor`、`writing-mode`…；全文只有 HTML→SVG 的属性名映射表里出现过它）⇒ 属性被剥掉，
靠它做"字符中心对齐"的文本一律退回字母基线：**小节序号**（框内数字整个偏上），
以及**增时线 `-`**、**段层括号**的居中。应用侧（iJipu）不经 DOMPurify，所以只有插件有这个问题。
现在改用 `DOMParser` 解析 `image/svg+xml`（属性原样保留、不碰 `innerHTML`），
解析失败才回退旧路径 —— 另外用严格 XML 解析器核过随包示例谱渲染出的全部 SVG 都是合法 XML。

**③ 深色主题下右上角 `</>` 看不见 —— 用户看到的是宿主那枚，它只跟主题取色**

实时预览里插件那枚会撤掉、屏幕上那枚是 **宿主自己的**「编辑此块」，
而它的颜色来自 `--embed-action-color`（深色主题下是浅灰）——压在**恒为白色**的谱面纸张上
对比度只有 **1.4:1**。现在给"本插件的块里"那枚补上与本插件那枚相同的"半透明深底 + 白字"
（对比度 **4.76:1**）。

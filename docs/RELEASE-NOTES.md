## 引擎 0.40.0 → 0.40.1

- **`adj1005` 带跳房子的多段反复播放顺序**：终点线优先取本跳房子自己的 `|]` / `:|]`
  （`:|]/` 也以自己为终点）；只有不封闭的 `|]/` 才往后找 `:|`/`:|:`/跳跃线。
  跳过落点 = 末尾线之后的第一小节（**不得落回线前**，`|/` 不计）；`|:` / `:|:` 的段首越过纯 `|/`。
- **`adj1006` 从音符起播保留遍次读数**：`startNoteId` 非空时的三条早退不再丢 `passMarks/maxPass`；
  整曲从音符起播 / 练习段 / 标记段三条切片路径都按 0 点重排并补当前遍。
- **`adj1007` 跨行跳房子的右半段盖住行首小节**：行首音符偏移改用 `18.4 × noteScaleOf(noteSize)`；
  只认"第一音左侧"的小节线，没有就从边距+2 起画（不再写死 18.4 而漏最左一小节）。

## 内嵌应用 0.70.0 → 0.70.1

- 与引擎同步的上述三处修复；应用版本号、CHANGELOG、CLI 手册与官网素材同步到 0.70.1。

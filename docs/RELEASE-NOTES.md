# 爱记谱 iJipu 0.20.0

> **设置面板改版**：改**多页签**（页面 / 字体 / 行距 / 渲染 / 音色库 / 说明，一屏一组、不必长距离滚动），
> **「收藏音色」改成分类流式列表**（与 iJipu 应用「音色库」同一套 GM 14 类：可折叠、整组选/消、
> 顶部全选/全消/反选 + 搜索、实时「已选 N / 128」）。
> 同时**修掉两处"设置不同步"**：「保存为插件默认」不再把某一份谱的 frontmatter / 源内值写成**全库默认**，
> 且在别处改完插件默认后，「设置 → iJipu」页签会**就地刷新**。
> 随 `@ijipu/engine` 0.21.0 同步（GM 音色分类表收敛到引擎，应用与插件共用一份）。
> 0.19.1 → **0.20.0**（MINOR：设置面板交互与结构改版）。

**设置面板：多页签**（`adj631`，用户要求"如 linter 插件一样多页签，减少滚动"）

- 六个页签：**页面 / 字体 / 行距 / 渲染 / 音色库 / 说明**；横向可滚、选中页签用主题强调色。
- 每个设置页签顶部有一行说明：**这一页是本库全局默认**，只对"谱面源码没写 `# jps-config`、
  笔记 frontmatter 也没写"的键生效。
- 「说明」页签：优先级说明 + 「复制全部键名」「复制 frontmatter 模板」两个工具按钮（原来在页面顶部）。

**收藏音色：分类流式列表**（`adj631`，用户要求"参考应用全局设置里的流式分类列表"）

- 按 GM 14 类分组（钢琴家族 / 色彩打击乐 / 风琴 / 吉他 / 贝斯 / 弦乐 / 合奏合唱 / 铜管 / 簧管 /
  笛管 / 合成 / 民族其它 / 打击乐 / 声音效果），**点分类标题可折叠**，右侧显示该类 `已选/总数`，
  并有「选本组 / 消本组」。
- 顶部工具条：**全选 / 全消 / 反选 + 搜索框**，右侧实时显示「已选 N / 128」；输入关键词后**平铺**成一行行结果。
- 音色按 `flex-wrap` **流式排布**（不再是一条 128 行的长列表），列表区自带滚动。
- 勾选/整组操作**就地更新**，不会把列表滚回顶部。

**修复：两处"设置不同步"**（`adj631`，用户报"预览页面的设置与设置-iJipu 里的设置项不同步"）

- **核对结论**：两边的**字段集完全一致**（同一份 `defs.ts`）；**值不同是正常的**——预览页面的「⚙ 设置」
  显示的是**这一份谱的生效值**（含笔记 frontmatter 与源码 `# jps-config`），设置页签是**本库全局默认**。
  现在对话框里明确写了这句口径。
- **真 bug ①**：「保存为插件默认」此前把**整份草稿**写进插件设置，而草稿初值 = 这份谱的生效值
  ⇒ 点一下就把**本谱专属的设置**变成**全库默认**（「设置 → iJipu」冒出一堆你没设过的值、别的笔记观感也变）。
  现在**只写你在该次对话框里真正改动过的项**；等于引擎默认的会从插件设置里移除（保持稀疏）；一项没动则提示、不写盘。
- **真 bug ②**：在预览对话框里改完插件默认后，已打开的「设置 → iJipu」还停在旧值上。现在会**就地刷新**
  （页签自己改的不刷新，避免打断正在输入的控件）。

**升级**

- 设置面板换了样子但**字段与取值口径没变**：原来的"全局默认"仍是全局默认。
- 「收藏音色」的勾选集与以前一致（同一份 `hqEnabled`）；现在可以按类快速挑选。
- 若你之前点过「保存为插件默认」，建议到「设置 → iJipu」核对一遍（旧行为可能把某份谱的值存成了全库默认）。

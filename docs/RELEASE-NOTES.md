# 爱记谱 iJipu 0.25.2

> 随 `@ijipu/engine` **0.27.0** 同步：**重叠跳房子（`["2.3."`）与演奏顺序**，
> 以及 **`{tp}` 替谱段的占宽 / 歌词 / 两端括号全面修复**。
> 0.25.1 → **0.25.2**（PATCH：仅引擎同步，插件自身写法与设置不变）。

**一、新增「重叠房子」与演奏顺序（`adj653`）**

- 一间房里可以写**多个遍次**：`[+++"2.3." … ]`（`[` 标签里的**所有数字**都算这间房服务的遍次）。
  三遍制的曲子不用再拆成两间房，写法更短。
- **反复优先于跳转**：`:|&ds` 这类"反复线与跳转记号同处一根线"的写法，
  先按反复线走一遍、**再**跳转；此前整曲会少一遍，且 `["4."` 那间房一次都不响。

**二、`{tp}` 替谱段的排版修复（`adj654`~`adj664`）**

- **歌词配对**：改成按**歌词槽位**把字对到替谱音上 —— `@`（跳过一个音）**照占一槽**、标点不占槽；
  **主旋律该行音符不够时由替谱音补上**（不再出现"`可做，` 不显示"）；多个 `{tp}` 同一行时各管各的字。
- **占宽**：替谱音在拍**内部**改用"覆盖该拍位那个主旋律音的**槽**"来铺开
  （不再继承主旋律音符的墨迹宽窄）⇒ 16 分音符最小间距 **5.2 → 9.0px**，不再重叠。
- **同一行多个 `{tp}`**：互不重叠时**共用一条视觉行**（不再各占一层、白留行高）。
- **两端括号**：右括号不再被小节线"钳"进末音；兜底边界由"行右缘"改为**页面边距线**
  （可以扩到小节线，但不会越出边距）；行末替谱会**预留**括号宽度（末段 `)` 间距 **0.2 → 13.8px**）；
  左括号取**半个间距**（**9.7 → 4.9px**），左右观感更均衡。

**升级**

- **无需改谱**：不写 `{tp}`／跳房子的谱面，渲染与演奏结果与之前**逐字一致**。
- 若你的谱面里原本用两间房表达"一间房服务两个遍次"，现在可以合并写成 `["2.3."`（不改也照常工作）。

# 爱记谱 iJipu 0.8.0

> 本版随 `@ijipu/engine`（0.10.4 → **0.11.0**）同步一项**新语法**：**临时伴奏 `{bz … }`** 与
> **临时多声部 `{dsb … }`**。插件侧不需要改代码，只是引擎换新版——笔记里可以直接写这两种语法了。
>
> 用途：**一段旋律里临时加一层伴奏、或临时分成两个声部**，不必把整首曲子都改成多声部。
> 用 `{bz … }` / `{dsb … }` 直接写在曲行中间，段与主旋律**同拍位对齐**、谱面正确显示。

## 新增：临时伴奏 `{bz … }` 与临时多声部 `{dsb … }`（adj427）

- **`{bz … }` 临时伴奏**：段内容是**伴奏声部**，画在主旋律**上方**、与主旋律同一拍位**垂直对齐**。
- **`{dsb … }` 临时多声部**：段内容是**主声部**；该段覆盖范围内的主旋律自动成为**第二声部**，
  两层上下叠放、同一拍位对齐，并用一对大花括号 `{ }` 把两层括在一起。
- **叠加段不占主旋律拍位**：`{ … }` 前后主旋律的拍位连续不变；段宽 = `[段所在拍位, 段所在拍位 + 段自身总拍数)`。
- **括号两种写法任选**：段内不写 → 程序给整段加一对圆括号；段内自己写 `&zkh` / `&ykh` →
  按你写的位置绘制并**预留占宽**（不要两种同时用，否则会出现两层括号）。
- 段内可正常写音符、时值、小节线；段必须**成对闭合**、**不支持嵌套**（写错会给出明确报错与正确写法）。

```jps
V: 1.0
B: 临时伴奏示例
D: C
P: 4/4
Q: 3 4 | {bz 1 2 3 4 | 5 6 7 1'} 5 6 7 1' | 1' 7 6 5 | 5 5
```

## 试听：两个声部各用各的音色

- **`{bz … }`**：上层（段内容）= **伴奏声部** → 第 2 可用音色（脚本第 2 条 `Y:` 行；没有则「手风琴」）、
  力度 **0.75**；下层（包络内主旋律）= **主声部** → 音色与力度**完全不变**。
- **`{dsb … }`**：上层 = **主声部**（该曲行音色、力度 1）；下层 = **第二声部**（第 2 可用音色、力度 **0.75**）。
- 段层与主旋律**同一拍位同刻发声**；落在 `|: … :|` 里时**每一遍都会演奏**。
- **播放色块按音色着色**：不同音色不同颜色；重叠区**上下两层各一个色块、同步移动**。
  （既有单声部仍是红块、Q1 红 / Q2 蓝，观感不变。）
- 插件侧「试听音色」的全局覆盖只作用于**主声部**，不会把重叠区两个声部压成同一种音色。

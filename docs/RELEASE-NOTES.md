# 爱记谱 iJipu 0.29.0

> **嵌入版：在 Obsidian 里直接用完整的 iJipu 编辑 `.jps`**（不必再装外部桌面端）。
> 0.28.3 → **0.29.0**（MINOR：新增"嵌入版"能力）。

**一、嵌 入 版（本次重点）**

- **文件 → 左侧栏出现「爱记谱」图标**（可在设置里关掉）：点开是一个**完整的 iJipu**
  —— 编辑、排版、试听、导出都在，和网页版/桌面版是同一个应用。
- **以当前 Obsidian 文库为工作区**：不需要选文件夹、不需要文件系统授权，文件树就是你的文库。
- **打开库里的 `.jps` 就是完整编辑器**（不再只是轻量预览 + 源码框）；
  笔记里 **`![[xx.jps]]` 仍是原来的轻量预览**（笔记里塞一个完整编辑器既难看也没必要），
  它的工具栏按钮由「应用打开」改为「**编辑**」，点它用嵌入版打开这份谱。
- **设置 → iJipu → 「嵌入版」**三个选项：使用嵌入版（开关，控制左侧栏图标）、
  工作区子目录（留空 = 文库根）、跟随 Obsidian 主题。
- 关掉开关即完全回到原来的轻量渲染（**可回退**）。

**二、本次修掉的问题（均来自你的真机实测）**

| 现象 | 原因 | 处理 |
|---|---|---|
| 点文件树里的 `.jps` 打开的是"未命名"，并提示"还没有设工作区…" | 工作区记录归一化时把**没有句柄/路径**的记录当损坏记录丢掉了，于是文库工作区从来没设上 | 放行"宿主桥"记录（文库工作区） |
| 点「新工作区」报 `SecurityError: … Cross origin sub frames aren't allowed to show a file picker` | 浏览器**禁止跨源子框架**弹文件选择器 | 嵌入版里**不再出现**"选文件夹/切换工作区"入口；「打开/另存为」改为走工作区（文库写作） |
| 嵌入版**图标全都不显示** | 资产里有中文文件名，浏览器把 URL **百分号编码**，而服务用原始串查表 ⇒ 永远查不到、全部 204 | 服务侧 `decodeURIComponent` 后再查表 |
| 左侧栏图标提示文案 | — | 改为「**打开爱记谱**」 |

**三、体积**

嵌入版网页（含 37 个图标与全部前端资源）内联在 `main.js` 里，发布物**仍是三个文件**
（`main.js` 约 2.8 MB）。未使用的资源（PWA 图标、遗留 SVG 等）**不打包**。

**四、升级方式**

插件市场更新即可。首次点开「爱记谱」图标会启动一个**仅本机**的本地服务
（`127.0.0.1`，带一次性令牌）承载该页面 —— 不联网、不对外。

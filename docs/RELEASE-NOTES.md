# 爱记谱 iJipu 0.18.0

> 同步 `@ijipu/engine`（0.19.0 → 0.20.0）——带来**替谱段 `{tp … }`**、**临时段（`{bz}`/`{dsb}`/`{tp}`）的占宽与对齐规则**，
> 以及一批**演奏/排版修复**（替谱只替代自己那一行、段内同音连音合并、段内音不再被挤丢、段层第一条减时线不再被宿主 CSS 抹掉）。
> 插件自身同时做了**设置口径对齐**：新增「临时段」三项、数值项按引擎范围钳制、字段/标签与应用逐项一致、
> 段层虚线拖拽改 `segmentRowGap.*`（此前会误改谱面行距）。
> 0.17.0 → **0.18.0**（MINOR：一条全新语法 + 一套设置口径对齐）。

**新增**

- **替谱段 `{tp … }`**（`adj629`，主项目新语法）——写在**歌词行**里，**第 k 段歌词 = 第 k 遍**：
  - 例：`C2: 有 人 唱 情 歌 {tp 4/ 3// (6,// 6,//) 1/.} 借 一 丝 …` ⇒ 第 2 遍那一小段改奏替谱内容；
  - 预览：画在**所属歌词行的上方**，自动加一对圆括号（与音符留间距），与主旋律**逐拍同位**（不做横向压缩）；
    覆盖区里的**歌词字跟着替谱层的音走**；层高**整体压扁到 2/3**（字号不变，一眼区分"这是另一遍"）；
  - 演奏：第 k 遍以替谱**替代**主旋律那一段（音色/力度与主旋律一致），**替谱奏完立刻回主曲部**继续；
    只替代**它自己那一行**（不会波及别的 `Q:` 行）；
  - 编辑体验：点谱面替谱音符跳脚本、试听中从该音起奏、"格式化"按曲行规则给段内补空格（歌词原样）、编辑器按曲部着色。
- **临时段占宽/对齐规则**（`adj629m`）：`{bz}` / `{dsb}` / `{tp}` 覆盖的**曲部**按**多声部规则**参与占宽
  ——同一拍取"两层里更密的那一层"的需求，主旋律该拍一并撑宽、段内 16 分音符也拿得到足够槽宽（行总宽不变）。

**设置口径与应用对齐**（`adj629q`，本次插件侧改动）

- **字段集与文案**：插件的设置面板 /「⚙ 排版」对话框与应用「布局 / 字体」逐项一致——
  行距类改为「曲部与词部间距 / 词部与词部间距 / 曲部与曲部间距 / 曲部与上词部间距」，
  「布局模式」「描述头高」「首行至描述头间距」「乐器显示」「歌词压缩」「序号间隔」等同步改名；
  应用不暴露的 `bar_gap` 插件设置里也不再给控件（仍可随谱携带）。
- **新增「临时段」三项**：`bz 段上下间距` / `dsb 段上下间距` / `替谱行与下方歌词间距`——
  读写 `segmentRowGap.{bz,dsb,tp}`（子对象），默认值取引擎 `SEGMENT_ROW_GAP_DEFAULT`（22 / 22 / 14）。
- **数值范围**：15 个谱面数值项按引擎 `GUIDE_LIMITS` / `GUIDE_LIMITS_EX`（与应用同一份表）**越界即钳制**
  ——此前插件不钳制，同一字段两处能填出不同范围。
- **排版辅助虚线**：段层（`{bz}`/`{dsb}`/`{tp}`）虚线改画紫色、拖动写 `segmentRowGap.*`
  （此前被当成普通曲行，拖它会误改 `height_ciqu*`）。
- **frontmatter 模板**：嵌套字段 `segmentRowGap` 合成一行 YAML
  （`ijipu_segmentRowGap: {bz: 22, dsb: 22, tp: 14}`）——此前会写成三行互相覆盖、值还会变成 `[object Object]`。

**修复**（随引擎同步而来）

- 多行谱里"某几拍没演奏出来"——替谱静音判据**没带行号**，跨行误伤（`adj629o`）。
- 段层里的**同音连音**没合并（`{tp 4/ 5// (6// 6/) 5/}` 的 `(6// 6/)` 奏成两次起奏）（`adj629p`）。
- `{bz}` 被强加一对圆括号、段内末音被挤丢（`adj629l`）；替谱拍位被"圆到 0.1"导致替谱后那一拍不发声、
  括号压住首音、歌词不对替谱音（`adj629i`/`adj629k`）。
- 预览里段层**第一条减时线**消失（宿主 CSS `rect:first-child` 误伤 `<g>` 内元素；改为按
  `data-page-bg` 选，`adj629n`）。插件侧样式一直没用到那条危险选择器，故插件不受影响。

**升级**

- 装了新版即可用 `{tp … }`：在**第 2 段歌词行**（`C2:`）里写 `{tp … }`；没有反复结构的谱面会提示"该段替谱不会生效"。
- 想让替谱层离歌词更远/更近：**设置 → iJipu → 行距 → 替谱行与下方歌词间距**（或直接开「排版」拖那条紫色虚线）。
- 分享给他人显示一致：用「⚙ 排版 → 随谱固化」把非默认项写进源码 `# jps-config`。

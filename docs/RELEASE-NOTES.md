# 爱记谱 iJipu 0.38.0

> **本版是功能版 + 引擎同步版**（MINOR）：谱面菜单**重排为四组**、**新增「保存为 PNG / 保存为 SVG」**、
> 图片分辨率**升级为设置**、修掉**谱面视图一侧留大块空白**；引擎侧同步应用的"新建模板去掉 `S:` 行、
> 多声部连音按声部隔离、各声部按音色列表区分、小节序号落位"；**内嵌的 iJipu 应用**更新到 **0.57.0**。
> 0.37.0 → **0.38.0**。
> **既有谱面、`.jps` 语法、代码块参数全部零改动** —— 变的只是菜单组织方式、新增两个保存出口，
> 以及渲染出来的几何。

## 新增与调整

### 谱面菜单重排为四组（`adj912`）

原来的菜单项混在一起，现在按"从显示到导出"的顺序重新分组（桌面 · 代码块）：

| 组 | 内容 |
|---|---|
| **显示** | 设置（原来的「排版」入口） |
| **操作** | 复制图片 / 复制 SVG 文本 / 复制谱面源码 / **保存为 PNG** / **保存为 SVG** |
| **分辨率** | `1×` / `2×（默认）` / `4×`（单选打勾） |
| **导出范围** | 页面（整页 + 留白）/ 谱面（墨迹 + 每边 2px）—— 文案不变 |

之后「源码」「打开」两组照旧（由能力标志决定是否出现）。

### 新增「保存为 PNG / 保存为 SVG」

- 存到**这份谱所在目录**、用**谱面主名**（例：`花又期二重奏.jps` ⇒ `花又期二重奏.png`）；
- **同名不覆盖**：已存在就依次加序号（从 2 起取第一个空位，例 `花又期二重奏 2.png`）；
- `a.PNG` 与 `a.png` 视为同一个文件（大小写不敏感）；
- **手机端隐藏这两项**（手机端存图走嵌入版，与既有口径一致）；
- PNG 复用既有位图通道（含 `pHYs` 物理分辨率），SVG 走矢量通道。

### 图片分辨率升级为设置（`adj912`）

- 原来菜单里是三项「复制为图片（1× / 2× / 4×）」，现在改成**一个设置项**（`imageScale`，默认 **2×**）：
  菜单「分辨率」组与设置页「说明」页签读的是**同一个值**（`DEFAULT_IMAGE_SCALE` 一处定义）；
- **只对位图出口生效**（复制图片 / 保存为 PNG），**SVG 不受影响**；
- 「导出范围」组对四个出口都生效。

### 修复：谱面视图一侧留大块空白（`adj915`）

墨迹量取的坐标没先归位到页面坐标系，遇到带变换的 DOM 就会量偏。现在统一在**共用的量取函数**里：

- 用 `svg.getCTM()⁻¹ · el.getCTM()` **把元素坐标归位**到页面坐标系；
- 再与**页面盒求交**（`clipBoxToPage`），超出页面的部分不参与墨迹；
- **不按入口分叉**：代码块 / `.jps` 文件页 / 嵌入三处共用同一份量取；
- ⚠ **导出 / 复制 / CLI 的量取口径没变**（仍是 `rangeBox` 的"每边 2px"）。

### 嵌入块 / 代码块：按用户裁定**保持全宽**（`adj917` 回退 / `adj920`）

- 0.37.0 之后的中间版本曾让嵌入块/代码块**跟随同上下文段落文字的首行缩进**；用户 2026-10-13 拍板
  **「嵌入块保持全宽」** ⇒ **整条撤回**（`src/paraIndent.ts` 删除、`scorePane.ts` 里的 `applyParaIndent`
  删除、`styles.css` 的规则删除），回到"块级盒占满段落盒"的原行为 —— **不是新功能，就是恢复原样**；
- 顺手清掉一条**从未生效的死规则** `.ijipu-embed .ijipu-score`（`.ijipu-score` 与 `.ijipu-embed`
  加在同一个元素上，后代选择器永远匹配不到）；
- **代码块的 2px 内边距保持现状不动**（用户："现在看嵌入块和代码块观感是一样的"）。

## 引擎同步（应用 0.57.0 的引擎，逐字节同步到 `vendor/engine`）

- **「新建」模板去掉描述头 `S:` 行**（用户 2026-10-13 要求）：新建出来的空白谱只带
  版本/标题/署名/调号/拍号 + 谱面主体 + 页面设置块，不再自带"本乐谱使用…编制"这类自述说明；
  想在谱尾写说明自己加 `S:` 即可。**`S:` 里的网址渲染成可点链接这个功能照旧**（只是不再由模板提供样本）。
- **多声部连音线跨小节**按声部隔离（承接 0.37.0 的修复，本轮把边角补齐）；
- **各声部按音色列表区分**（缺 `Y:` 的声部按启用音色列表顺延，不再一律同色）；
- **小节序号落位**（`{dsb}` 临时多声部下跟着主声明的小节线走）。

## 更新：内嵌的 iJipu 应用 0.56.0 → **0.57.0**

按项目的**顺序铁律**生成：先在应用仓库定稿版本号（0.57.0 已提交并推送），
再 `npm run build:embed` + `node scripts/embed-emit.mjs`。跨仓闸门 `adj733`（嵌入产物版本 == 应用 `APP_VERSION`）**通过**。

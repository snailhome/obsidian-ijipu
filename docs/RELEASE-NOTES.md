# 爱记谱 iJipu 0.42.1

> **本版是跟随版**（PATCH）：内容三块 —— ① **同步引擎**（`0.39.0 → 0.39.1`：试听标记段的端点解析兜底、
> 变音记号与前倚音让位）；② **内嵌的 iJipu 应用**从 `0.68.0` 跟到 **`0.69.0`**（标记段收口 + 手册新增「标记段」一节）；
> ③ **设置页「诊断」精简**（插件自身代码）。0.42.0 → **0.42.1**。

## 为什么是 PATCH

插件自身只做了一处**精简**（诊断页把三块辅助诊断合成一块），没有新增能力；引擎与应用都是修复与文档，
按 SemVer 走 **PATCH**。

## 引擎：`0.39.0 → 0.39.1`

- `resolvePracticeRange` 端点解析补两档兜底：**忽略分组号**只按同声部+序号就近夹紧 → 再不行就落序列最前/最后。
  口径变化：**端点不再报 missing**（宁可范围偏一端，也不静默退回全曲）。
- `render`：变音记号（`#`/`b`/`♮`）与**前倚音**共存时，**倚音给升降调符让位**（`7/$[6/]` 不再重叠）。
- `extendRangeEndToSlurEnd`：连音线延长改用 **token 身份映射**（解析序号 ≠ 放置序号时的错位）。
  注：应用界面当前**不调用**它（用户口径：连音线由用户指定末音），算法与断言保留备用。

## 内嵌应用：`0.68.0 → 0.69.0`

- 标记段：端点解析兜底、画线与播放**统一区间**（所见即所听）、画线强制含两个端点、
  续行只吸附小缺口（不再把**跳房子 1** 这种不演奏的整段画上线）、**循环时用 ⟲ 代替端点竖头**。
- 试听**暂停续播位置**修正：`startTimers` 在 `start()` 之后才 `seek(from)`，不再把暂停点清零；
  循环中续播也能继续触发。
- 应用内「使用手册」新增**「标记段（练一小段）」**整节（怎么标 / 怎么播 / 循环与 3-2-1 倒数 /
  谱面怎么显示 / 跨行与反复 / 遍次下拉 / 停止音与连音线的口径 / 存在哪）。

## 插件：设置页「诊断」精简

  点击预览区显隐工具条」合成一块，一行一项）、**嵌入版本地服务**。
- 「一键复制全部诊断」的文本同步合并，与页面上看到的块一致。

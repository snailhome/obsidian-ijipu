# 爱记谱 iJipu 0.5.1

> 本版修好 **`![[xxx.jps]]` 嵌入区显示不出谱面**这个老毛病（前两版各修过一次，都没修到根上）：
> 根因是宿主 Obsidian 对"没有嵌入处理器的文件"会走一条占位兜底分支，而它的 `empty()`
> 正好把插件渲染好的谱面清掉。现在改为**向 Obsidian 注册 `.jps` 的嵌入渲染器**——
> 由宿主把渲染权交给我们，绕不开、也不再有占位块。
> 同时按反馈打磨了谱面工具栏：显示模式**改回下拉列表**（弹层用 Obsidian 自己的菜单，配色跟随主题）、
> 设置图标改为**齿轮**（与 iJipu 应用一致）、「谱面自带设置 N 项」移进设置对话框、
> 窄容器下按宽度**逐级图标化**（优先保住谱面文件名）、四个按钮的高度与宽度统一。

## 修复：`![[xxx.jps]]` 嵌入区不显示谱面（根因 + 两次误修的教训）

- **现象**：笔记里写 `![[檐下声.jps]]`，嵌入区只出现一个"写着文件名的未知嵌块"，没有谱面；同一份谱用 ```jps 代码块、或点开 `.jps` 文件视图都正常。
- **根因**（逐行核对 Obsidian 1.13.7 本体 `obsidian.asar`）：嵌入解析入口 `EmbedRegistry.load(ctx)` 的第一步是 `containerEl.empty()`，然后按扩展名找 embed creator —— `.jps` 没有，于是走 `FileEmbed` 兜底：给容器加 `file-embed mod-generic` 并塞一个文件名占位块。**用户看到的"未知嵌入块"就是它，而它那句 `empty()` 把插件先前渲染的谱面清掉了。**
- **两次误修（记在这里，避免再走回头路）**：
  1. 用 `MutationObserver`「被覆盖就重挂」——判空写的是 `container.querySelector('.ijipu-score')`（只查**后代**），而 `.ijipu-score` 恰恰加在容器**自身**上 → 永远判为"没挂上"，自我重挂瞬间耗尽重试配额，等宿主真正覆盖时已无机会。
  2. 在 post-processor 里给容器打 `is-loaded` 让宿主跳过（机制本身没错，嵌入解析只挑 `:not(.is-loaded)`）——但真机诊断日志显示：**同一个嵌入存在两个容器**，一个 `<span class="internal-embed">`（markdown 产物，post-processor 看得到），另一个 `<div class="internal-embed" src="…">`（宿主/其它方直接交给 `EmbedRegistry.load`，**完全不经 post-processor**）。只标记得到看得见的那个，可见的那个照样落到兜底分支。
- **修复**：给 `.jps` 注册 **embed creator**（Obsidian 自己的 Canvas / Bases 插件用的同一条路径）。命中后宿主不再走 `FileEmbed` 兜底 —— 无论嵌入元素是谁创建的、从哪条入口进来，渲染都必须交给我们。`app.embedRegistry` 不可用时（更老的宿主）退回 post-processor 认领作为兜底。
- **顺带**：渲染抛错时给出可见的 `⚠ 渲染失败：…`（此前只会留一片空白）；被嵌入的 `.jps` 在别处被修改时，嵌入区自动重画。

## 新增：嵌入区的「打开谱面文件」入口

- 接管嵌入后，宿主原本那个"点开文件"的占位块不再出现，于是把入口补回**工具栏右端**：链接图标 + 谱面名，点击打开该 `.jps`；容器放不下时只留图标（悬停说明照旧）。

## 改动：显示模式改回下拉列表（并修掉嵌入里按钮被撑宽）

- 三个图标按钮改回**下拉列表**：按钮上是「模式图标 + 当前模式名 + ▾」。
- 弹层**不用原生 `<select>`**，改用 **Obsidian 自己的 Menu**：配色跟随主题、当前模式带勾选。原生 `select` 有两处顽疾，一并根除：
  1. 弹层底色由平台决定 —— 深色主题下会变成"浅底浅字"，看不清；
  2. 在某些上下文里它会被算进布局，把视图按钮撑成**两倍多宽**（真机截图确认，且只在嵌入模式复现，`.jps` 文件视图正常）。
- 另加两道保险，杜绝该按钮再被任何上下文改变宽度：`width: max-content` + `flex: 0 0 auto`。

## 改动：窄容器按宽度逐级退让（优先保住谱面文件名）

- 阈值按**工具栏自身宽度**判断（CSS `@container`），所以右侧栏、分栏里的嵌入也判断正确：
  - **≤400px**：先图标化「试听 / 排版 / 设置 / 视图」（图标含义明确、悬停有说明），四个按钮同时**等宽**（桌面 36px / 嵌入 32px）；
  - **≤250px**：最后才把「打开谱面文件」也图标化 —— 谱面名是"这份谱是什么"的唯一标识，优先保住它。
- 「试听」按钮改用 **SVG 播放/停止图标**（原先是 `▶ 试听` 纯文字，文字一藏就什么都不剩）。

## 改动：工具栏其他打磨

- **控件高度统一**：移动端 Obsidian 会给 `button` 套触控尺寸（`--touch-size-*`），而「视图」是自绘外壳、不吃那套尺寸 → 两者不等高。现在统一由 `--ijipu-ctl-h` 钉死（桌面 24 / 嵌入 21 / 移动端跟 `--touch-size-xs` 与 `--touch-size-xxs`），四个按钮与右侧链接同高。
- **设置图标改为齿轮**，形状与 iJipu 应用顶栏「页面设置」完全一致（轮环 r=3.1 + 8 根轮齿 + 中心轮毂 r=1.3），只按插件既有约定把线宽定为 1.8（轮环/轮毂）/ 1.5（轮齿），以适配深色主题下的可读性。
- **「谱面自带设置 N 项」移入设置对话框**：原先挂在工具栏上（挤占按钮位置、明细只能悬停看），现在对话框顶部列出**具体是哪几项、值是多少**，也正好解释下面控件初值的来源。

## 验证

- `tsc -noEmit` + esbuild 构建通过；`npm run smoke` **108 项断言全绿**。
- `![[檐下声.jps]]` 嵌入在**阅读模式与实时预览**下均正常显示谱面（真机实测确认；此前两版都只显示"未知嵌入块"）。
- 工具栏在**嵌入 / `.jps` 文件视图 / ```jps 代码块**三种入口下形态一致；窄宽度退让、图标态等宽、移动端控件等高均按上述阈值生效。

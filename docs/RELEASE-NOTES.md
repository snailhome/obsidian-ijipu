# 爱记谱 iJipu 0.34.1

> **本版是 0.34.0 之后的实测修复批**（PATCH）：把三处预览的**工具条显隐/落位**、
> **手机端滚动**、**嵌入块编辑**、**诊断方式**这一串"真机才暴露"的问题逐条修掉。
> 0.34.0 → **0.34.1**。**既有谱面与 `.jps` 语法零改动**。

## 工具条：显隐与落位（本版主要工作，均由真机实测驱动）

- **外侧落位改用 `position: fixed` + 挂到 `document.body`**：此前"浮在块外上方"会被
  **相邻 CM6 行盖住**（诊断：坐标正确、无裁剪层，但命中测试命中的是 `div.cm-line`）——
  `z-index`/放开 `overflow` 都不足以跨出祖先的**层叠上下文** ⇒ 移到 body 后彻底摆脱裁剪与层叠约束；
- **不再预留空带**（推翻 0.34.0 里"块内空带"的做法）：按用户口径，**块与普通块一样排版**、
  工具条**浮在其它元素之上**（允许遮挡）；
- **取消"悬停显示"**：改为**点击预览区显/隐**（唯一手动开关），键盘仍可唤醒；
- **显隐改为"块进视界才显示 + 3 秒倒计时从进视界起算"**（单一状态机 `syncToolbarVisibility()`）：
  · 块不在视界（或还没尺寸）⇒ 不显示、也不计时；
  · 块进入视界 ⇒ 显示并从**这一刻**倒计时 3 秒；
  · 用户点击 ⇒ 手动显/隐，**手动显示后不再自动收起**；
  · 用 `hiddenByViewport` 区分"因离开视界隐藏"与"用户主动收起"；
- **手机端"显示后马上又隐藏"/"再也显示不出来"**：触摸会合成鼠标事件 ⇒ 悬停那套自动收起要去掉；
  并且手机端 CSS 的"常显"规则需要 `is-user-hidden` 才能压过 ⇒ 三处隐藏路径统一补该标记；
- **搬到 body 的工具条保留上下文标记**（`ijipu-ported-mobile` / `ijipu-ported-embedded`）：
  否则 `.is-mobile` / `.ijipu-embedded` 两条按祖先匹配的**尺寸规则**失效 ⇒ "点击显示的"与
  "滚动中的"工具条**按钮大小不一致**；
- **孤儿工具条清理**：嵌入面板销毁**不走 `destroy()`**（实测）⇒ 改为按"容器是否仍在文档里"判定，
  并在每次挂载与每次外侧落位时清理（修"工具条卡在原地不消失"）。

## 手机端预览滚动

- **不能上下滚**（桌面端正常）：诊断显示 `.ijipu-file-view[overflow=auto ✓ 但 scroll=1020/1020 无溢出]`、
  而**面板自己被压小**（`flex: 1 1 auto` ⇒ 内容在面板内部溢出、不计入父容器可滚高度）✗
  ⇒ 面板与 SVG 层显式 **`flex: 0 0 auto`**（按内容高度参与布局）⇒ 父容器得到真实溢出 ⇒ 可滚；
- 另加 `touch-action: pan-y`（预览容器 + 谱面子树）与移动端惯性滚动；
- 一并撤销了 0.34.0 里"把滚动交给宿主"的尝试 —— 诊断证明**宿主各层全是 `overflow-y: hidden`**
  （`workspace-leaf-content` 明明有内容可滚却 `hidden`）⇒ 唯一能滚的就是我们自己那层。

## 嵌入块与编辑入口

- **手机端嵌入 `![[x.jps]]` 的「编辑」点了没反应**：按钮分派在手机端走 `onToggleSource`，
  而**嵌入宿主没有这个回调** ⇒ 空调用 ✗ ⇒ 改为**回退到 `onEdit`** ⇒ 现在**直达源码编辑**（用户已确认）；
- 嵌入/代码块的自动格式化、着色、错误提示与 0.34.0 一致（本版未改这部分口径）。

## 谱面留白

- **谱面视图四边 2px 留白**：裁剪分支原来把 viewBox 设成**墨迹紧边界** ⇒ 贴边 ✗
  ⇒ 裁剪框**四边各外扩 2px**（与"退回按边距裁剪"那一支同口径）。

## 诊断方式（用户要求："不要一直来回交互，手机反馈诊断并不方便"）

- 设置新增**独立「诊断」页签**（不再干扰「说明」里的有用信息），每块**点击即复制（标题 + 内容）**，
  另有「一键复制全部诊断」；
- 新增 **「生成完整诊断报告」**：**一次取样**得到
  「环境（版本/平台/视口/DPR）＋**滚动链路**（沿途 overflow/touch-action/contain/scrollHeight÷clientHeight
  ＋"可滚容器 = …"小结）＋**工具条实物**（在 DOM 哪里/是否显示/坐标/内联样式/上下文标记）
  ＋面板布局＋最近交互记录」，**点一次即自动复制**，粘贴即可定位；
- 工具条落位诊断改为**每次显示都刷新**（原来每个元素只判定一次 ⇒ 贴出来的永远是别的实例、
  且常是"视口外"的那条 ✗）。

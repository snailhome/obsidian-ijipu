# 爱记谱 iJipu 0.5.0

> 本版随 `@ijipu/engine` 同步 **adj392 / adj393 / adj394**：渐强/渐弱在**默认设置下终于能显示**
> （此前只在"拍级"布局渲染，而默认是"空间优先"→ 静默不显示）、`!` 可收在 `-`/`.` 之后、
> 音符注释新增 `+`/`-` 抬升降低；并**修掉插件一个把告警当错误的老毛病**——
> 以前只要谱面有一条语法告警（多空格、孤立 `&`、无法识别的符号…）整页就变成"解析失败"，
> 现在告警**不再阻断渲染**，且在谱面下方显示，并同时给出**正确语法规则**。

## 修复：语法告警不再阻断渲染（插件此前把 warning 当致命错误）

- **现象**：同一份 `.jps` 在 iJipu 应用里能正常显示，在 Obsidian 里却整页提示「简谱解析失败」。
- **根因**：引擎 `parseJps` 的 `errors` 数组**同时装 error 与 warning**（用 `severity` 区分）；应用侧一直按 severity 分级，插件的 `renderScore`/`renderScoreFull`/`playScore` 三处却只看 `errors.length > 0` → **任何一条告警都会让谱面不渲染**。
- **修复**：新增纯逻辑 `src/parseIssues.ts`（`splitParseIssues`）按 severity 拆分——只有 `error` 阻断渲染/试听，`warning` 随渲染结果一并返回；`scorePane` 在谱面下方显示可展开的告警区 `⚠ N 条语法告警（不影响显示）`。

## 新增：告警/错误同时给出「正确语法规则」

- 引擎 `ParseError` 新增 `hint`（**正确写法 + 最小示例**），17 处报错点全部补齐；插件在错误区与告警区逐条显示 `正确写法：…`（如「引号要成对闭合，如 `1"渐强" 2`」）。

## 引擎同步 adj392：音符注释抬升 / 降低（新语法）

- 紧接注释引号后的 `+`/`-` 逐级抬升/降低注释文本（每级 2px，可多个）：`1"注释"+`、`1"注释"--`，与跳房子 `[+`、连音线 `(+` 同一套记法。`-` 只在**紧接引号**时归注释；增时线请写在注释之前（`1-"注释"`）。

## 引擎同步 adj393：渐强/渐弱（`<`/`>`/`!`）在默认设置下不显示

- **根因**：`<`/`>`/`!` 是装饰 token，处理它的代码只在「拍级（duration）」布局路径里，而**默认配置是"空间优先"**（`noteSpaceLayout: 'space'`）→ 记号被静默丢弃；多声部块同样不处理。
- **修复**：新增引擎纯模块 `layout/hairpins.ts`（事件流 + 起止解析），**三条布局路径（拍级 / 空间优先 / 多声部）共用**；退化写法（起止落在同一处）不再画成一根竖线，并给出告警 + 正确写法。

## 引擎同步 adj394：`!` 可结束于任意「有时值的元素」之后

- 起点 `<`/`>` 仍取所跟音符的数字槽中心；`!` 除写在音符后外，还可写在该音符的**增时线 `-`** 或**附点 `.`** 之后 → 终点取该元素右缘（`1 2 3 < 4- ! 5`；`4--` 更靠右）。渐强/渐弱**不跨行**（未写 `!` 时收尾于本行行末）。
- **语法明确**：渐强/渐弱**只有 `+` 抬升，没有 `-` 降低**（`-` 始终是增时线）；`&编码+` 是**加长版**（`&sby+` 加长波音、`&cy+` 长颤音），`&编码` 也没有 `-`。连音线 `(-` 的 `-` 属于连音线（不是前一个音符的增时线），紧贴写法 `1(-` 会给出提示。

## 验证

- 插件 `npm run smoke`：**108 项断言全绿**（新增：仅告警的谱面可正常渲染、含错误的谱面才阻断、跨行渐强属告警、十类语法问题全部带正确写法）；`tsc -noEmit` + esbuild 构建通过。
- 引擎侧（主项目）`npm run smoke` 失败项与基线一致（无新增），并在 **iJipu 应用内**用无头 Chrome 实测过：合法写法出渐强/渐弱、`3<---!` 无告警、`3<!` 与 `1"未闭合` 分别给出告警/错误并附「正确写法」。
- `vendor/engine` 与主项目**逐字节一致**（29 个文件 MD5 零差异）。

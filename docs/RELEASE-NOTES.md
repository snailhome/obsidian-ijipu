# 爱记谱 iJipu 0.9.0

> 本版随 `@ijipu/engine`（0.11.0 → **0.12.0**）同步 **21 项引擎改动**，并修好插件侧试听的三处口径问题。
> 主题：**把临时伴奏 `{bz … }` / 临时多声部 `{dsb … }` 打磨到可用**，以及**多声部试听让每个声部真正用上自己的音色**。
> 插件侧不需要改笔记里的写法——原来怎么写的谱子，现在会显示得更准、听得更对。

## 改进：试听色块与应用完全一致（adj452）

- **逐声部逐块**：色块按「曲行 + 声部 + 音色 + 声部角色」分别绘制——多声部各声部一块、
  `{bz … }` 重叠区与 `{dsb … }` 上下两层**各有各的色块并同步移动**（此前每行只画得出一块）。
- **高度按谱面几何**：优先使用引擎按曲行几何算出的上下边界（多声部按**声部中线**分块、
  临时段按**上下层中线**分块），色块不再互相覆盖、也不再往歌词方向压。
- **配色按声部角色/音色**：`{bz}` 上层 = 蓝（伴奏）、`{dsb}` 下层 = 绿（第二声部）、
  `{dsb}` 上层 = 红（主声部）；普通旋律按**音色**着色（同一音色恒定同色，`@乐器名@` 切换音色时颜色跟着变）。
- **多组多声部时色块跑到第一组位置**——已修：一页里有好几组多声部时，第 2 组及之后的色块
  不再跳到第 1 组那一行。

## 修复：多声部试听「只响一种音色」（两条根因）

1. **播放通道按「乐器族」分配**：同族的两个音色（钢琴+电钢琴、小提琴+大提琴、长笛+竖笛…）会撞在
   同一条 MIDI 通道上，后设的音色把先前声部一起改掉，且已设过的音色不会再补发 ⇒ 整首只剩一种音色
   （实测 17 个事件里 11 个用错音色）。现在**一个音色独占一条通道**，并跳过 GM 打击乐通道
   （`9 钢片琴` 这类音色不再走样）。
2. **音色名解析表不完整**：`Y:` / `@乐器名@` 写「设置 → 音色库」列表里的名称，此前 **128 个名称里有 101 个
   解析不到自己的音色**（例如「弦乐合奏1」「弦乐合奏2」都变成同一个 48，「高音/中音/次中音/低音萨克斯」
   都变成 65）。现在音色表收敛为引擎唯一来源，列表里的**任意名称**都能解析，也支持列表里的**编号**写法（`Y: 21`）。
   > 注意一处行为变化：`Y: 电钢琴` 由旧口径的 4 改为按列表口径 **2**（GM 标准：2 是电钢琴、4 是电钢琴1）。

## 变更：「默认音色」不再压掉伴奏与曲内 `@乐器名@`（adj450）

- 设置里的「默认音色」只在**谱面没有显式指定**时生效：**伴奏/第二声部**（`{bz}`/`{dsb}` 重叠区）与
  曲内 `@乐器名@` 一律保留自己的音色（与 iJipu 应用同口径）。
- 设置项说明补上覆盖关系：**选了具体音色会覆盖谱面里的 `Y:` 乐器**——要按谱面各声部音色演奏，请选「自动」。
  （默认就是「自动」。）

## 同批引擎修复（随本版一起生效）

- **`{bz}` / `{dsb}` 段内音符的光标联动**、**段层与主旋律逐拍对齐**、**段内内容/末音丢失**、
  **段层色块左右边界**（段内小节线为硬上限、`{bz}` 以前后小节线为界、`{dsb}` 以大括号为界、
  首个色块从起始音符开始、末音延伸到段层右界）、**`&zkh` 位置**、**倚音音色**、**重叠区占宽**、
  **临时段上下层间距可调**（谱面 `segmentRowGap`，缺省 22px）等。
  逐条说明见 iJipu 应用 v0.21.0 的 `CHANGELOG.md`。

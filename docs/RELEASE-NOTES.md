# 爱记谱 iJipu 0.21.0

> 随 `@ijipu/engine` **0.22.0** 同步：**倚音自身的修饰符** —— 倚音括号内、某个倚音数字之后可以再挂一个
> `&` 编码（`6/[5/&tu]`）：`&tu`/`&die`/`&da` 画在该倚音**正上方**、`&shy`/`&xhy` 画在该倚音**右侧**，
> 字形/图形与主音符同款，尺寸**随倚音一起等比缩小**。
> 0.20.0 → **0.21.0**（MINOR：引擎新增标记能力，插件侧解析/排版/渲染随之生效）。

**倚音上可以挂修饰符了**（引擎 `adj632`/`adj632b`）

- 写法：编码写在**倚音括号内、该倚音数字之后**——
  - `6/[5/&tu]` 该倚音加**吐音**（粗体 **T**，画在倚音正上方）；
  - `6/[5/&die]` 加**叠音**（**又**）；`6/[5/&da]` 加**打音**（**扌**）；
  - `6/[5/&shy]` 加**上滑音**、`6/[5/&xhy]` 加**下滑音**（画在倚音右侧）。
- **多倚音**时挂在紧挨着它的那一个倚音上：`6/[5/&shy2/]` 只有 `5` 带滑音。
  右侧的记号会把**后一个倚音**与**本音符的占位**一并推宽，不会压到相邻数字或主音符。
- **只支持上面这 5 个**。力度 / 波音 / 颤音 / 独立标记 `&zkh`/`&ykh`/`&hx` 写在倚音括号里**不支持**，
  会给出告警提示（不会静默丢弃）；编码写在数字**之前**也会提示。
- 倚音修饰符**只影响谱面显示**，不改变演奏时值。

**尺寸与位置口径**

- **上方三个**：字号 = 倚音字号 × 10/18 —— 与主音符的记号**同一把尺子**，所以记号跟着倚音一起变小，
  不会"比倚音还大"。
- **右侧两个**：墨迹**与倚音数字等高**、纵向与数字**齐平**（同顶同底）、左缘**紧贴**数字右侧。

**升级**

- 老笔记无需改动：没写倚音修饰符的谱面，排版与渲染**逐像素不变**（占宽公式在无修饰时与旧版一致）。
- 想在笔记里用：照上面写法直接写在 `jps` 代码块里即可；插件会跟着引擎一起解析、排版、渲染。

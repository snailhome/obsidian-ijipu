# 爱记谱 iJipu 0.23.0

> 随 `@ijipu/engine` **0.24.0** 同步（**多声部排版 + 变音角标 + 连音线**一轮打磨），
> 并修好**插件自己的默认值口径**：在应用里显示正常的谱面，在插件里**不再提示「未随谱携带」**。
> 0.22.2 → **0.23.0**（MINOR：引擎排版行为更新 + 插件侧提示口径变更）。

**一、插件默认值口径：与应用一致（用户要求）**

- 用户口径："将插件的默认值体系与应用的默认值体系保持一致，以确保在应用正常的谱面设置，在插件中不会有未随谱携带的提示项。"
- 现在「未随谱携带」以**本库默认层**为基线——**代码默认 ← 插件设置**（**不含**笔记 frontmatter）。
  与插件设置一致的值，在用户眼里就是"本库默认值"，等价于应用里的代码默认值，**不再提示**。
- 于是提示只剩**这篇笔记特有**的差异（典型来源 = 笔记 frontmatter `ijipu_*`）——它提醒你
  "只把代码块复制给别人时，这些值不会跟着走"，用**「随谱固化」**即可消除。
- 「⚙ 设置」对话框里新增一段说明，写明"本页设置与「未随谱携带」提示的关系"。
- 引擎侧 `configCarryover(code, effective, baseline)` 新增第三个参数；应用侧不传（应用没有本机默认层）⇒ 口径不变。

**二、随引擎同步的排版改进（打开旧谱即可见，写法不变）**

- **带变音的音符更紧凑**：变音角标（`#`/`$`/`=`）的占宽改为按**墨迹宽**算（不再按字宽）——
  此前 `♮`（全角 CJK 字形：字宽 1em、墨迹 0.355em 且居中）会**压进自己的数字**，`#`/`b` 又会白留约 2.4px。
  现在 13px 音符下 `#` 的占宽 7.62 → **5.40px**；描述头调号与音符变音的"净距"也统一为同一条规则（0.2px）。
- **插件也实测字形度量**：用 canvas 量出 `#`/`b`/`♮` 的墨迹宽与左偏交给引擎（此前只有描述头那条实测），
  角标占宽与位置**按你本机字体**算——换字体也不会压字或多留缝。
- **多声部行里拍内音符按时值分开**：撑满行（一行小节数达到「两端对齐最小小节数」）此前把富余宽全堆在
  拍与拍之间 ⇒ 拍内一个数字一个槽宽挤在一起、拍间空一大截。现在富余摊进**拍宽本身**，
  拍内按 0.5/0.25 这样的**时值比例**分开，拍间只剩正常间距；行总宽不变（末小节线位置不动）。
- **连音线更贴合**：两音符连音线的圆弧垂度改为随跨度自适应（原来写死 9px ⇒ 跨度小的时候弧高≈跨度，
  立成半圆、看着像悬在两个数字之间）。跨度 ≥32px 的长连音线**保持原样**。
- **多声部块的大括号更贴首个音符**（与首音符间距 15.65 → **7.11px**）、**小节线两侧净距统一**
  （1.10 → **3.20/3.30px**）、不等长拍不再吃掉末小节线的净距。

**升级**

- **无需改任何谱面**：`.jps` 写法没变；打开旧笔记即按新规则排版。
- 如果你的笔记里描述头字号调得较大：角标净距按字号等比（与 0.22.2 一致）。
- 「未随谱携带」提示会**变少**（只统计 frontmatter 造成的差异）——这是预期的修正，不是丢信息。

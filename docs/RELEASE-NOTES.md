# 爱记谱 iJipu 0.37.0

> **本版是引擎同步版 + 预览口径修复**（MINOR）：把**内嵌的 iJipu 应用**从 0.55.2 更新到 **0.56.0**
> （带来多声部试听两处修复、小节序号落位、时值格判定口径、删「虚音符」写「连音线连接点」），
> 并修掉插件自己的一批实测问题：手机端工具条、点「编辑」不消失、编辑跳转不进历史、

> **既有谱面、`.jps` 语法、代码块参数全部零改动** —— 变的只是渲染出来的几何与交互细节。

## 引擎同步（应用 0.56.0 的引擎，逐字节同步到 `vendor/engine`）

- **多声部连音线跨小节会演奏成两个音**（用户报 `(5---|5)---|` 应为 1 个 8 拍音）：连音合并的判据读的是
  **全局的"上一个已发事件"**，而多声部序列**按小节交替**拼 ⇒ 一过小节线就变成对声部的音 ⇒ 不合并。
  现在 5 个状态量**按声部隔离**（实测真谱末句 F4 起奏 3 次 → **1 次 6363ms**）。
- **未设置音色时各声部音色/色块不区分**（用户报图）：缺 `Y:` 的声部原来一律回落同一音色，而色块按音色名
  去重 ⇒ 必然同色。现在声部 1 用第 1 个可用音色、声部 ≥2 **按启用音色列表顺延**（不传列表时保持旧口径）。
- **小节序号落位**：方框上沿距小节线 **1px**；`{dsb}` 临时多声部把另一水平线下移时，序号**跟着主声明的小节线**走；
  "主声部"改按 `voice===1` 认（此前按"最上面一排"，`Q2:` 写在 `Q1:` 前会挂错行）。
- **「时值格 ⊇ 墨迹」转为真断言**：原先报的 16 处不合规**全是探针口径错**，现已按口径重写并覆盖两条布局路径。
- **删掉「虚音符」这个幽灵概念**（文档写了、实现从来没有）、按用户口径写入**连音线连接点**：
  `(2)` 括号紧贴数字 = **结束前一条连音线 + 起下一条**（语法文档 §2.7 含用户例子 `(1 - (2) - | 3) --- |`）。

## 插件修复（用户实测）

- **手机端工具条统一只图标**（原来按容器宽度决定 ⇒ 收起/点开两副样子）；
- **点「编辑」先收工具条再派发**，并在**打开 `.jps` 时清掉残留工具条**（用户建议的"打开时检查一下"做法）；
- **「编辑」跳转进导航历史**（同一页签打开 + 换视图前先真·打开文件）⇒ 系统「返回」能回到笔记；
- **谱面视图的裁剪**：墨迹盒**仍用原来那套**（量渲染后的真实内容盒），四周留白回到 **每边 2px**
  —— 与**导出 / 复制 / CLI 同一份口径**（`rangeBox`，几何全在引擎里）；
- **排版辅助虚线的盒与 SVG 视框同源**（原来自己算的是"整页裁四边距"盒、与墨迹盒原点不同 ⇒ 谱面模式下虚线整体错位 ✗）：
  现在直接读 SVG 当前的 `viewBox`，读不到才退回自己算。

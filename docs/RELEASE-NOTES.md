# 爱记谱 iJipu 0.19.0

> 同步 `@ijipu/engine` 0.20.0 的后续改动——**描述头默认排布改「贴角」**（空设置下左栏贴左下角、
> 右栏贴右下角、居中栏贴区域上沿），**`D:` 行与 `J:` 行的 `=` 号严格同列**，
> 以及**两个行距默认值**按用户口径调整（曲部与上词部间距 −5、曲部与词部间距 20）。
> 插件自身的设置文档与断言同步补齐：README 对照表的默认值跟着引擎走（左右边距 50）、
> 补 `showBarCount` / `barCountInterval` / `segmentRowGap` 三行，并新增一组长期守卫断言。
> 0.18.0 → **0.19.0**（MINOR：谱面观感变化 + 设置文档/口径收口）。

**描述头观感变化**（随引擎同步而来，`adj629u`/`adj629v`）

- **默认排布 = 贴角**：`# jps-config` 为空（或没写过描述头位置）时——
  左侧（`D:`+`P:` 调式与拍号、`J:` 节拍）**贴描述头区域左下角**（末行在下、上行往上排；
  只有其中一行时它自己就贴下沿）、右侧（`Z:` 作者）**贴右下角**（首行在上、末行贴下沿）、
  居中（`B:` 标题/副标题、`Y:` 乐器）**贴区域上沿**往下接。行距随描述头/标题字号自动缩放。
- **`D:` 行与 `J:` 行的 `=` 号同列**：`D: Bb` 预览成 `1 = ♭B`、`J: 62` 预览成 `♩= 62` 时，
  两个 `=` 严格对齐（此前带升降号时会右偏一个角标宽，`Bb` 实测 8.8px）。
- 拖过描述头文字的笔记不受影响：那些元素仍按 `metaPos` 的自定义偏移走。

**行距默认值调整**（`adj629w`/`adj629y`）

- **曲部与上词部间距**（`ijipu_height_ciqu_lyric`）：10 → **−5**（歌词行与下一行曲部压得更紧）。
- **曲部与词部间距**（`ijipu_height_quci`）：15 → **20**（曲部与它下面那行歌词拉开 5px）。
- 没写过这两项的笔记会跟着变；显式写过（frontmatter 或 `# jps-config`）的笔记保持原值。

**插件侧同步**（`adj629z`）

- `README.md` 的 frontmatter 对照表：**左右边距默认 40 → 50**（引擎早已是 50，文档一直没跟上）；
  补 **显示小节计数**（`ijipu_showBarCount`，默认 false）、**序号间隔**（`ijipu_barCountInterval`，默认 4）、
  **临时段上下间距**（`ijipu_segmentRowGap`，`{bz: 22, dsb: 22, tp: 14}`）三行；
  `ijipu_bar_gap` 标注"设置面板未提供控件、仍可用 frontmatter 携带"。
- `scripts/smoke-frontmatter.mts` 新增 `[3f]` 8 条长期守卫：`defs.ts` 每一行都必须是引擎字段、
  行内不许自带 `default:` 字面量、数值范围逐项等于引擎表、**README 对照表覆盖每一项且默认值与引擎一致**、
  `segmentRowGap` 三个子项写全、应用暴露的谱面字段插件都有控件（跨仓对账）。
  插件 smoke 由 181 条增至 **189 条**。

**升级**

- 想微调描述头位置？在预览里直接拖那些文字（写入 `metaPos`，随谱保存）；没拖过就是上面的贴角默认值。
- 想恢复旧观感（更松的行距）？在 `⚙ 排版` 或设置里把「曲部与上词部间距」填回 10、「曲部与词部间距」填回 15。
- 分享给他人显示一致：用「⚙ 排版 → 随谱固化」把非默认项写进源码 `# jps-config`。

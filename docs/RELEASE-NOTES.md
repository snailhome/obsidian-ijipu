## 为什么是 MINOR 而不是 PATCH

按 `docs/VERSIONING.md`「两库版本号各自独立、各按自身代码更新量递增」：本轮插件仓库自己**动了源码**
（`src/scorePane.ts` 接线手势与提示条、新增 `src/overlayAssets.ts` 取图、`styles.css` 新增提示条样式、
`src/embed/bridge.ts` 新增 `readAsset` op）⇒ 是**新增能力**，判 **MINOR**
（PATCH 只留给"插件自身源码零改动、仅重生成嵌入产物"那种版本，先例：`0.31.1`/`0.35.1`/`0.39.x`）。

## 新增：水印 / 背景层的预览手势（`Alt` 一族，EP-13）

- **键位**（用户终裁＝方案 A「Alt 一族全包」）：`Alt+滚轮` 缩放该层、`Alt+Shift+滚轮` 旋转该层
  （每次 5°，**绕元素自身中心**）、`Alt+左键拖动` 平移该层（1pt 取整，按住 `Shift` 吸附页面中心）。
  为什么不用 `Ctrl`：那是浏览器/桌面壳的**页面缩放**热键，而 `Ctrl+单击` 在应用里是"从这里试听"
  ⇒ `Alt` 一族与它完全不冲突。
- **三条前提缺一不动**：①工具条「排版」开着 ②该层已启用（勾了「启用水印」/「启用背景」）
  ③该层有内容（文本水印要有文字、图形水印与背景要有路径）。
- **角落提示条**：满足前提时出现在谱面右下角，写明键位；**水印与背景都可调**时另有「调整对象」
  切换器（只有一层可调就直接作用在它身上，不显示切换器）；该层还只活在**插件设置**里时给一句
  红字提醒「尚未写入谱面」。
- **落盘口径与应用同源**：手势期间只做预览，**松手 / 停手 400ms** 才写进这份谱的 `# jps-config`；
  且写的是"**被调那一层整层**"（启用 + 内容 + 参数）——不会留下"只写了一个宽度值、层却是关的"
  这种半截配置（应用侧本轮就踩过这个坑，见 `E-2026-438`）。
- **不抢别人的手势**：`Alt+拖动` 落在**辅助虚线**上时走的是"平移层"，不会变成拖虚线（虚线的
  `pointerdown` 按住 Alt 时直接让位）。

## 新增：代码块预览能读图（EP-09 插件侧）

- **两条取值**：`图.png`（含 `img/图.png`）**相对承载它的那份笔记**；
  `[[图.png]]`（含 `[[图.png|别名]]`）走 Obsidian 的**链接解析**（vault 全域、可跨目录）。
- **安全与策略取自引擎**（与应用、与宿主桥同一份）：只收 `png/jpg/jpeg/webp/gif/bmp`（**拒 SVG**）、
  单文件 16MB 上限、路径里任何位置出现 `..` 一律拒。
- **不静默降级**：图不在 / 类型不支持 / 超上限 / 解码失败，都会弹一句能照着做的提示。
- 读盘是异步的，而面板重画是同步的 ⇒ 先按"没有图"画一版（谱面立刻可见），资源到位后自动重画一次。

## 修复：「谱面」视图的裁剪（内容包围盒排除水印/背景层，EP-11②）

`scorePane.measureContentBox()` 原先只排除整页白底 `[data-page-bg]`。水印/背景两层是**按整页可视**
画的（背景图常铺满整页、重复水印更是铺满整页）⇒ 被算进内容盒 ⇒ 「谱面」视图（只显示有内容的部分）
退化成整页。现在同时跳过 `[data-overlay]`。⚠ 这一条**在文本水印上早就已经踩到**（本插件早就画文本水印），
不是等图片通道做完才出现。

按 `adj770` 逐文件 SHA256 比对：`vendor/engine` 与应用引擎**53 个文件、缺失 0、内容不同 0、插件侧多余 0**。

`v0.62.0` 并推送），**再** `npm run build:embed` + `node scripts/embed-emit.mjs` 重生成嵌入产物。
跨仓闸门 `adj733`（嵌入产物版本 == 应用 `APP_VERSION`）**通过**（产物里 `appVersion: "0.62.0"`）。

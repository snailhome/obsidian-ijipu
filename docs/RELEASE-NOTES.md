# 爱记谱 iJipu 0.24.1

> 随 `@ijipu/engine` **0.25.1** 同步：修好**连音线跨跳房子**的一处漏网——**起点与房子隔了整行音符**时
> 两条延续线**一条都不画**。
> 0.24.0 → **0.24.1**（PATCH：纯引擎渲染修复，写法不变）。

**问题：隔得远就不画了**

- 0.24.0 起支持"跨房子连音线"（`(5 |["1." 5) … |]["2." 5) … |]["结束句" 5)`）。但引擎里跨行连音线的
  渲染分支写死了「**相邻两行**」——起点与房子首音之间**隔着整行音符**（≥2 个视觉行）时，按"误输入"
  直接不渲染。
- 典型情形就是"中间还有一段旋律"的曲子：房子 1 的跨线连音在第 1 行，房子 2 / 结束句的首音在第 3 行
  ⇒ **两条延续线一条都看不到**。

**现在：隔多少行都接续**

- 延续线（以及只有它）允许**跨任意行**，只在**终点所在行**画「该房子的起始小节线 → 首音」那半条弧。
- 起点那一行照旧**不多画**（保持房子 1 那条显式连线的干净观感）。
- **普通跨行连音线不受影响**：仍然只在相邻两行画左右两半（跨 3 行以上按误输入不渲染）。

**升级**

- **无需改任何谱面**：`.jps` 写法不变。只有"房子首音写了孤立 `)`、且前面存在一条跨越该房子起始
  小节线的连音线、两者相隔 ≥2 行"的笔记会**多出这两条延续线**——这正是本次要修的。

## 内嵌应用 0.84.0 → 0.84.1

- **渐强/渐弱起点与抬升量一起搬**：`6--- <+++ !` → `6<+++ ---!`。之前只搬 `<` 一个字符，`+++` 留在原地 ⇒ `---` 跑到起点前、`+++` 成了游离记号，渐强的位置和高度都变了；现在记号连同整段 `+` 一起落到该音符的增时线/附点之前。
- **连音线 `)` 后补空格**：`7[6/]--- <+++ | 7-- ) !` → `7[6/]<+++ --- | 7) --!`；倚音 `[...]` 整体算一个音符块，记号落在 `]` 之后，不会被插进方括号里。
- **重排同口径**：重排从 token 重拼源码时也走同一套归一，重排后不再退回旧格式。
- 内嵌应用版本 `0.84.1`（`WEBAPP_META.appVersion`）。单文件 HTML 1,867.2 KB（1,776,684 字符），51 个资产（49 个图标）/ 166.0 KB。

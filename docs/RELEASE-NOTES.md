# 爱记谱 iJipu 0.22.2

> 随 `@ijipu/engine` **0.23.1** 同步：**描述头调号 `D: C#` / `D: Bb` 的角标间距修好**——
> `♯`/`♭` 与调号字母此前要么**压字**、要么**间距过宽**，现在**紧贴但不重叠**（墨迹净距 0.2px）。
> 0.22.1 → **0.22.2**（PATCH：引擎渲染修复 + 插件侧改为自己实测字体度量）。

**问题在哪（为什么前后几版都不对）**

- 引擎是纯 TypeScript、**拿不到字形度量**，此前只能估/量 `♯`/`♭` 的宽度来给它"让位"。
  可这个字形在不同字体里差别极大：它可能是**西文窄字形**，也可能是**全角 CJK 字形**——
  后者**占宽 1em 里只有 0.62em 有墨，右侧还空 1.75px**（13px 调号实测：占宽 9.75、墨迹 `[2.00, 8.00]`）。
- 于是"按占宽让位"会把那 1.75px 留白也算进间距（看起来就是**明显过宽**），"按墨迹让位"又依赖宿主实测。

**这版怎么修的**

- **引擎改成内联排版**：角标与字母写在同一条 `<text>` 里（角标是个变小上移的 `<tspan>`），
  相对位置**由字体自己的推进量决定**，不再由引擎猜；两者之间只加固定 **0.2px** 净距。
- **插件也开始实测字体**（此前**一个实测值都不传**）：用 canvas 量出 `♯` 的**占宽**与**墨迹右缘**，
  把"右侧留白"交给引擎**补偿掉** ⇒ 不论什么字体，角标与字母的墨迹净距都严格是 **0.2px**。
  顺带把 `1 = ` / `1 ` / `♩` 也实测传入，描述头 D 行与 J 行的 `=` 号在插件里也对得更准。
- 临时转调记号 `转1=Ab` 与描述头共用同一套画法，**一并修好**；净距随描述头字号等比。

**升级**

- **无需改任何谱面**：写法不变，只是 `D: C#`、`D: Bb` 这类调号的角标与字母贴得更紧（不再压字、也不再有缝）。
- 若你的笔记里描述头字号调得较大：净距会按比例放大（16px 调号下 0.25px），观感一致。
- 老笔记的其它渲染与试听行为**完全不变**。

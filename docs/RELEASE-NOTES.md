# 爱记谱 iJipu 0.25.1

> 随 `@ijipu/engine` **0.26.0** 同步：**谱面文本里的链接自动可点**（用户要求）。
> 0.25.0 → **0.25.1**（PATCH：引擎同步 + 渲染层接线，写法不变）。

**谱面里的 URL 变成可点的链接**

- 你的谱子里写的那串网址（例如 `S:` 谱尾说明里的「本乐谱使用「爱记谱 https://ijipu.pages.dev」编制」）
  以前只是一串普通文字，点不动。
- 现在**自动变成链接**：预览里带**下划线**、鼠标移上去是**手型**，点一下就用**系统默认浏览器**打开。
- 覆盖位置（都是可以自由写文字的地方）：`S:` 谱尾说明、标题 / 副标题 / 作者 / 乐器名、
  音符注释（`1"注释"`）、小节线备注（`|"备注"`）。**写法不变、不需要任何新记号。**
- 识别规则：`http(s)://`、`ftp://`、`mailto:`；写 `www.example.com` 这种**不带协议**的也认
  （链接指向 `https://www.example.com`，显示文本仍是你写的原样）。
  **句末标点与中文括号不算网址的一部分**（`见 https://x.com。` 只把 `https://x.com` 变成链接）。
- **折行不会把网址拆开**：一行放不下时整串挪到下一行，不会出现两个半截链接。
- 点击走 `electron.shell.openExternal`（桌面端＝系统默认浏览器；移动端由宿主接管），
  失败会弹提示，不会"点了没反应"。

**升级**

- **无需改任何谱面**：不写网址的谱面，渲染结果与之前**逐字一致**。
- 想让新建的空白谱也带官网链接：本版起模板的 `S:` 行就是
  `S: 本乐谱使用「爱记谱 https://ijipu.pages.dev」编制`，那句网址点一下即可打开官网。
